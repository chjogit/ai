1장. HTML 개요

1. Web이란?
- 1-1. 개념 및 네트워크 기초 : Web (WWW), 인터넷 (Internet), IP, DNS, Port
- 1-2. 통신 프로토콜 : HTTP ,FTP, SMTP / POP, DHCP
- 1-3. URL 구조 분석 : http + 컴퓨터 주소/DNS + 기본 웹 포트 + 정보 경로

2. HTML5
	멀티미디어 : 플러그인(Flash 등) 없이 <audio>, <video> 직접 재생
	그래픽 : 하드웨어 가속 기반 2D(Canvas) 및 3D(WebGL) 구현
	통신 & 오프라인 : 서버 양방향 통신 지원, 오프라인 로컬 저장소 활용
	장치 접근 : 배터리, GPS, 카메라, 진동 등 디바이스 제어 API 제공
	스타일 : CSS3 기술 완벽 연동 및 지원

3. 웹 표준 문서의 3대 요소 : HTML, CSS, JavaScript
- 구조/표현/동작 분리 : 역할 분리를 통해 문서 경량화 및 유지보수성 향상

4. 웹 동작 체계 및 접근성
- 클라이언트 단 (Client-side) : HTML, CSS, JS
- 서버 단 (Server-side) : Java, Python, Node.js 등
- Ajax : 일부 영역 데이터만 업데이트
- 웹 접근성 (Web Accessibility) : 웹 표준 준수 필수

5. 개발 환경 및 툴
- 텍스트 에디터/IDE : VS Code, Visual Studio, EditPlus, Notepad++, Eclipse, IntelliJ
- 브라우저 : Google Chrome (개발자 도구 활용 및 웹 표준 검수)
