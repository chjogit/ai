2장. HTML 기초

1. 태그(Tag) 및 기본 구조
- 1-1. 태그 기본 개념
	기본 요소 : 열린 태그, 닫힌 태그, 태그 이름, 속성(Attribute), 속성값(Value)
	W3C 규격 준수, 단일 태그(닫기 생략/자체닫기) 존재 : <img />, <br />, <hr /> 등
- 1-2. HTML5 기본 구조
	<!DOCTYPE html>, <html lang="ko">, <head>, <body>

2. 문서 정보 및 설정 태그 (<head> 영역)
- <meta charset="utf-8" />
- <title>제목</title>
- <link href="경로" rel="stylesheet" />
- <style> CSS 코드 </style>
- <script src="경로"></script>

3. 글자 및 텍스트 태그
- 3-1. 제목 및 단락 : <h1> ~ <h6>, <p>, <pre>, <br />
- 3-2. 텍스트 서식 태그
	<b> / <strong>,	<i>, <em>, <ins>, <del>, <sup>, <sub>
	&lt; (<), &gt; (>), &amp; (&), &nbsp; (' ')
- 3-3. 하이퍼링크 태그
	<a href="URL" target="_blank">, <a href="#id명">

4. 목록 태그
	<ul> -> type: disc, circle, square
	<ol> -> type: 1, a, A, i, I / start
	<li>

5. 표 태그
- <table>, <tr>, <th>, <td>, <caption>
- 표 구조 분할 : <thead>, <tbody>, <tfoot>
- 셀 병합 : rowspan="n", colspan="n"

6. 멀티미디어 태그
- 6-1. <img />
	src="경로", alt="대체텍스트", width/height="크기"
- 6-2. <audio>
	주요 속성 : src="경로", controls, autoplay, loop, preload="auto/metadata/none"
