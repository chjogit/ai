7장. 생성자 함수 및 프로토타입

1. 생성자 함수 : function Constructor(args) { this.prop = value; } (대문자 시작)  
	- 인스턴스 생성: var obj = new Constructor(값들);
2. 프로토타입  공유 메서드 등록: Constructor.prototype.method = function() { ... }  
	- 속성은 생성자 내부(this.), 메서드는 프로토타입에 정의
3. new 키워드  동작 : 빈 객체 생성 → this 바인딩 → 코드 실행 → 객체 반환  
	- 미사용 시 : 전역 오염 또는 undefined 반환
4. Class : class Name { constructor() { this.prop = ... } method() {} }  
	- 메서드 자동 프로토타입 등록, new 없이 호출 시 TypeError
