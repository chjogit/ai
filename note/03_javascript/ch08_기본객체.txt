8장. 기본 객체 (표준 내장 객체)

1. String 객체
  	- length, concat(str), substring(start, end), substr(start, count)
  	- indexOf(str) / lastIndexOf(str), trim(), toUpperCase() / toLowerCase(),* replace(m, n) / replaceAll(m, n)
- 정규표현식 (Regular Expression) 활용
  	- pattern.test(str) - t/f, str.match(pattern) - 일치하지 않으면 null
2. Array 객체
- 배열 생성 방식
  	* 리터럴 : var arr = [1, 2, 3];
  	* 생성자 : var arr = new Array(); 또는 var arr = new Array(크기);
- 배열 정렬 : sort(), arr.sort((left, right) => left - right);
3. Date 객체
- getTime(), Math.floor(차이값 / (1000 * 60 * 60 * 24))
4 Math 객체
	- Math.abs(x), Math.max(x, y, ...) / Math.min(x, y, ...),  Math.random()
	- Math.floor(x) / Math.ceil(x) / Math.round(x)
