2장. 한글 형태소 분석 및 시각화

1. 자연어 처리 개요
- 자연어의 정의 : 사람이 일상생활에서 사용하는 언어
- 자연어 이해 : 형태소 분석, 품사 태깅(POS Tagging), 의미 분석, 시각화
- 모델 생성 : RNN, LSTM, GRU, seq2seq, Transformer
- 자연어 처리 수행 절차
	- 분석 후보 생성 : 형태소 분리 및 품사 태깅
	- 제약 조건 적용 : 언어적 규칙 확인 및 불용어(Stopwords) 처리
	- 최종 분석 및 활용 : 시각화(워드클라우드, Plot), 유사도 분석, 연관 분석, 딥러닝 모델 적용

2. 한글 형태소 분석 엔진
- 형태소 분석 엔진 공통 함수
	- morphs(),pos(), nouns()
- HanNanum, Kkma, Komoran
- Okt, MeCab, Konlp

3. 워드 클라우드 (Word Cloud)
- 텍스트 내 단어 빈도수를 시각적으로 표현하는 기법
- font_path(글자 폰트), width(가로 크기), height(세로 크기), background_color(배경색), max_words(최대 단어 수), relative_scaling(빈도 반응도), colormap(색상 팔레트)
- to_file()

4. 워드 임베딩 (Word Embedding)
- 단어를 고차원 공간의 벡터(좌표)로 변환하여 단어 간 거리 및 유사도를 계산하는 기법
- Word2Vec : sentences, window, min_count, workers, sg, index_to_key, most_similar()
