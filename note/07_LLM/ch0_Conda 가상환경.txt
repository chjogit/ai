 Conda 가상환경

1. 가상환경 조회 및 생성

- 목록 확인
conda env list
또는
conda info --envs

- 가상환경 생성 (-n은 --name의 약어)
conda create -n llm python=3.10 -y


- 가상환경 활성화
conda activate llm


2.  가상환경 내 Jupyter 적용

- pip 최신 버전 업그레이드
python -m pip install --upgrade pip

- 가상환경에 ipykernel 설치
conda install ipykernel

- Jupyter 설치 확인
conda list jupyter

- Jupyter에 커널 등록 (노트북에서 가상환경 선택 가능)
python -m ipykernel install --user --name llm --display-name "llm(ipykernel)"

- 등록된 커널 목록 확인
jupyter kernelspec list


3. 패키지 설치

** 허깅페이스

- PyTorch cpu 버전 설치
pip install torch==2.6.0 torchvision==0.21.0 --index-url 

- 기호 수학(SymPy) 및 파일 시스템 추상화 라이브러리
pip install sympy==1.13.1 fsspec

- Hugging Face 트랜스포머
pip install transformers==4.57.3

- 자연어 Tokenizer (SentencePiece)
pip install sentencepiece

- Hugging Face Hub 데이터 업/다운로드 가속 도구
pip install hf_xet

- 영-한 번역 품질 향상
pip install sacremoses


4. 커널 삭제 및 가상환경 제거 (필요 시)

- Jupyter 커널 목록에서 삭제
jupyter kernelspec remove llm

- Conda 가상환경 완전 삭제
conda env remove -n llm
