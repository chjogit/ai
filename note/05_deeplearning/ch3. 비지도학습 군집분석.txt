3장. 비지도학습 군집분석

1. 데이터 생성
- 비지도학습 군집분석 : 정답이 없는 데이터에서 유사성을 기반으로 그룹을 형성하는 기법
2. K-Means 군집화 로직 구현
- 초기 중심점 지정, 거리 계산 함수 (dist), 그룹화, 중심점 이동
3. 군집화 반복 수행 및 시각화
- 그룹 할당 및 중심점 이동 과정을 반복(for문)하여 중심점을 최종 수렴 위치로 이동
- 각 반복 단계별 중심점의 이동 경로와 최종 그룹화 결과를 차트로 출력
4. API(sklearn)를 이용한 군집화
- scikit-learn 모델의 종류 및 주요 메서드
	- 예측 모델 (지도학습 : 회귀, 분류) : fit(X, y), predict(X)
	- 군집 모델 (비지도학습 : 군집화) : fit(X), predict(X), fit_predict(X)
	- 변환 모델 (전처리/차원축소 : Scaler, PCA 등) : fit(X), transform(X), fit_transform(X)
- KMeans 파라미터
	- n_clusters, init, n_init, random_state(Seed), cluster_centers_, labels_
