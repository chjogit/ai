5장. OpenAI TTS API

1. 환경 설정 및 API 클라이언트 인스턴스 생성

- API 키 설정 및 클라이언트 인스턴스 생성
	- python-dotenv 패키지를 활용한 .env 파일 환경 변수 로드 수행
	- OpenAI 클래스를 통한 API 클라이언트 인스턴스 생성 과정
	- OPENAI_API_KEY 환경 변수 사전 설정 또는 api_key 인자 명시적 전달 필요
	- 환경 변수 또는 인자 미지정 시 OpenAIError 예외 발생

	ex)
	from dotenv import load_dotenv
	from openai import OpenAI

	load_dotenv()
	client = OpenAI()
	

2. 기본 TTS 변환

- 음성 변환 모델 및 응답 처리 방식
	- tts-1 모델을 활용한 기본 텍스트 음성 변환 수행
	- with_streaming_response.create 구문을 활용한 스트리밍 방식 응답 수신 및 파일 저장 처리
	- client.audio.speech.create 함수 호출을 통한 바이너리 오디오 데이터 응답 객체 반환

	- 주요 매개변수 구성
		* model: 음성 합성에 사용할 실시간 최적화 기본 모델 지정
		* voice: 출력 음성용 프리셋 목소리 선택
		* input: 음성으로 변환할 입력 텍스트 문자열 전달

	- response.content 속성을 통한 오디오 바이너리 데이터 추출 및 mp3 파일 저장
	- IPython.display.Audio 모듈 활용을 통한 Jupyter Notebook 내 오디오 재생 처리

	ex)
	# 변환할 텍스트 - with 구문을 사용하여 TTS 음성 생성 응답을 스트리밍 방식으로 받아오기
	text = 'Hello, OpenAI! This is a text to speech test.'
	with client.audio.speech.with_streaming_response.create(
		model="tts-1",
		voice="ash", # 사용하고자 하는 목소리 (ash, alloy, echo, fable, onyx, nova, shimmer)
		input=text,
	)  as response:
		response.stream_to_file('data/ch5_outputash.mp3')

	from IPython.display import Audio
	Audio('data/ch5_outputash.mp3', autoplay=True)

	response = client.audio.speech.create(
		model="tts-1",
		voice="alloy",
		input=text
	)

	audio_data = response.content
	print(f'입력 텍스트의 글자 수 : {len(text)} 개')
	print(f'생성된 오디오 데이터 크기 : {len(audio_data)} 바이트')

	with open('data/ch5_alloy.mp3', 'wb') as audio_file:
		audio_file.write(audio_data)

	Audio('data/ch5_alloy.mp3', autoplay=True)


3.1 여러 가지 음성 목소리 선택하기

- 프리셋 목소리 선택 및 활용

	- 6가지 표준 프리셋 목소리 제공
		* Alloy : 남성적이고 부드러운 음색
		* Echo : 맑고 청아한 톤
		* Fable : 동화 구연과 같은 따뜻한 톤
		* Nova : 친근한 여성 음색
		* Onyx : 깊고 진중한 남성 음색
		* Shimmer : 밝고 생동감 있는 여성 음색

	- voice 파라미터에 소문자 문자열 지정 방식

	- 영어 기반 최적화 모델이나 다국어 텍스트 발음 지원 가능

	ex)
	# 여러가지 목소리
	response_diff_voice = client.audio.speech.create(
		model="tts-1",
		voice="shimmer",
		input="this text will be spoken with different voices.",
		speed=1.8
	)

	audio_data = response_diff_voice.content
	print('음성 변환 데이터 크기 :', len(audio_data))

	with open('data/ch5_Shimmer.mp3', 'wb') as audio_file:
		audio_file.write(audio_data)

	Audio('data/ch5_Shimmer.mp3', autoplay=True)


3.2 TTS 모델 선택 : 실시간 vs 고품질

- 모델별 특성 및 성능 비교
	- tts-1 모델 : 빠른 응답 속도 중심의 실시간 상호작용 최적화 기본 모델
	- tts-1-hd 모델 : 응답 속도 대비 고품질 음성 생성 중심의 모델

	- 서비스 용도에 맞춘 속도와 음질 간 트레이드오프 고려 필요
	- 입력 문자 수 기준 요금 부과 구조

3.3 다국어 텍스트 변환하기

- 다국어 음성 합성 및 발음 조절
	- Whisper 모델의 지원 언어를 바탕으로 한국어 포함 다국어 음성 생성 지원함.
	- 영어 억양 기반 발음 특성 보완을 위한 쉼표 및 마침표 활용 텍스트 조절 방식 적용 가능함.

	ex)
	# 한국어 텍스트를 음성으로 변환
	kr_txt = '안녕하세요. 저는 오픈 API로 생성된 한국어 화자입니다.'
	response_ko = client.audio.speech.create(
		model = 'tts-1-hd',
		voice = 'shimmer',
		input = kr_txt,
		speed=0.9
	)

	audio_data = response_ko.content
	print('음성 오디오 데이터 크기 :', len(audio_data))

	with open('data/ch5_Shimmer_ko_hd.mp3', 'wb') as audio_file:
		audio_file.write(audio_data)

	Audio('data/ch5_Shimmer_ko_hd.mp3', autoplay=True)
	

3.4 발음 속도 조절하기
- speed 파라미터 조절
	- 0.25에서 4.0 범위 내 발음 속도 조절 설정
	- 기본값 1.0 기준 1.0 미만은 느린 발음, 1.0 초과는 빠른 발음 생성 처리

	ex)
	kr_txt = '안녕하세요. 저는 오픈 API로 생성된 한국어 화자입니다.'
	response_ko = client.audio.speech.create(
		model = 'tts-1-hd',
		voice = 'fable',
		input = kr_txt,
		speed=2.0
	)

	audio_data = response_ko.content
	print('음성 오디오 데이터 크기 :', len(audio_data))

	with open('data/ch5_Shimmer_ko_hd.mp3', 'wb') as audio_file:
		audio_file.write(audio_data)

	Audio('data/ch5_Shimmer_ko_hd.mp3', autoplay=True)

4.1 오디오 데이터 파일로 저장하기

- 오디오 바이너리 파일 저장 및 포맷 변경
	- 바이너리 쓰기 모드(wb)를 활용한 파일 기록 처리
	- response_format 파라미터를 통한 mp3, wav, aac, flac 등의 포맷 지정 지원
	- stream_to_file 메소드를 활용한 메모리 효율적 스트리밍 파일 저장 지원

	ex)
	kr_txt = '안녕하세요. 저는 오픈 API로 생성된 한국어 화자입니다.'
	response_ko = client.audio.speech.create(
		model = 'tts-1-hd',
		voice = 'fable',
		input = kr_txt,
		speed=2.0,
		response_format='wav'
	)

	audio_data = response_ko.content
	print('음성 오디오 데이터 크기 :', len(audio_data))

	with open('data/ch5_Shimmer_ko_hd.mp3', 'wb') as audio_file:
		audio_file.write(audio_data)
