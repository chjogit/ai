9장. RAG

1. RAG의 의미와 구성 요소

- 검색 증강 생성 방식의 정의 및 필요성 확인
	- LLM 어플리케이션 개발에서의 핵심 개념 파악
	- 사전 학습된 언어 모델의 한계 극복을 위한 외부 정보 활용

- Retrieval 단계의 데이터 취득 처리
	- 컴퓨터 시스템에 저장된 외부 자료 획득
	- 언어 모델이 보유하지 않은 보안 사내 자료 및 최신 정보 제공

- Augmented 단계의 문맥 결합 처리
	- 검색된 데이터를 언어 모델에게 전달하여 마치 해당 정보를 인지하고 있는 상태로 전환

- Generation 단계의 답변 생성 처리
	- 제공된 데이터를 기반으로 최적의 응답 결과물 생성


2. 벡터 데이터베이스와 유사도 검색

- 사용자의 질문과 관련 있는 데이터 판단 처리
	- 토큰을 1차원 배열인 벡터 값으로 변환하여 유사도 측정 수행

- 코사인 유사도 계산 구현
	- 두 벡터 사이의 각도를 이용한 유사도 측정 함수 정의

	ex)
	import numpy as np
	def cosine_similarity(vec1, vec2):
		"""두 백터 사이의 코사인 유사도 계산"""
		dot_product = np.dot(vec1, vec2)
		norm_vec1 = np.linalg.norm(vec1) 
		norm_vec2 = np.linalg.norm(vec2)
		if norm_vec1==0 or norm_vec2==0:
			return 0.0
		return dot_product / (norm_vec1*norm_vec2)

- 문서 로드 처리

- 문서 분할 처리

- 벡터 저장소 구축 처리
	- 임베딩 모델을 활용한 벡터 생성 및 저장소 적재

- 유사도 검색 및 답변 생성 처리
	- 질문을 이용한 유사도 검색 수행 후 프롬프트를 결합하여 언어 모델 전달


4. RAG chain

4.1 임베딩 및 대형 언어 모델 초기화

- 환경 변수 로드 및 임베딩 모델 설정 처리
	* 오픈에이아이 임베딩 모델을 활용한 벡터화 도구 정의
	* 챗 오픈에이아이 모델을 이용한 대형 언어 모델 인스턴스 생성

- 파인콘 벡터 저장소 연동 처리
	* 지정된 인덱스 이름을 기반으로 기존 벡터 데이터베이스 연결 수행

	ex)
	# 임베딩 & LLM 초기화
	load_dotenv()
	embedding = OpenAIEmbeddings(model = 'text-embedding-3-large')
	llm = ChatOpenAI(model = 'gpt-4.1-nano')

	index_name = 'tax-index-openai'
	database = PineconeVectorStore(
		embedding=embedding,
		index_name=index_name
	)

4.2 검색기 및 프롬프트 템플릿 구성

- 유사도 기반 검색기 생성 처리
	* 벡터 저장소를 활용하여 상위 세 개의 유사 문서를 추출하는 리트리버 구성

- 소득세법 전문가 프롬프트 템플릿 정의
	* 문맥과 질문을 동적으로 주입하기 위한 문자열 포맷 템플릿 생성

	ex)
	# Retriever 생성
	retriever = database.as_retriever(
		search_type='similarity',
		search_kwargs={'k':3}
	)

	# 프롬프트 템플릿
	template = f'''당신은 최고의 한국 소득세법 전문가입니다. 다음 문맥을 참고하여 질문에 최대 5문장으로 답하세요. 답을 모르면 모른다고 답하세요.
	질문 : {{query}}
	문맥 : {{context}}
	답변 : '''
	prompt = ChatPromptTemplate.from_template(template)


4.3 문서 포맷팅 함수 및 랭체인 파이프라인 구축

- 검색된 문서 텍스트 변환 처리
	* 검색 결과로 얻은 문서 객체들의 본문을 추출하고 줄바꿈 문자를 정제하여 연결

- 체인 파이프라인 결합 처리
	* 컨텍스트와 쿼리를 병렬로 전달하는 딕셔너리 구조 정의
	* 프롬프트, 언어 모델, 출력 파서 단계를 순차적으로 연결하여 실행 가능한 체인 완성

	ex)
	# 검색한 문서 텍스트 변환
	def format_documents(retrieved_docs):
		return "\n--\n".join([doc.page_content.replace('\n\n', ' ') for doc in retrieved_docs])

	# RAG chain
	rag_chain = (
		{
			"context":retriever | format_documents,
			"query":RunnablePassthrough() # 질문만 그대로 전달
		}
		|prompt
		|llm
		|StrOutputParser()
	)


4.4 체인 실행
- 사용자 질문에 대한 최종 응답 생성 요청 처리
	 연봉과 관련된 질문을 입력하여 소득세법 기반의 답변 도출 수행

	ex)
	rag_chain.invoke('연봉 5천만원인 직장인의 소득세는 얼만가요?')
