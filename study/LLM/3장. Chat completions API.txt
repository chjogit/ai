- OpenAI Chat Completions API 기본
	* GPT-4o-mini / gpt-4.1-nano

1. OpenAI API 소개 및 환경 설정

1.1 OpenAI API 개요

- OpenAI API: GPT 계열 대규모 언어 모델의 인터넷 기반 서비스 제공

- Chat Completions API
	- 챗봇 형태의 대화형 상호작용 엔드포인트 제공
	- 역할(role) 부여 메시지 목록 입력 시 모델의 다음 대화 내용 생성
	- GPT-4o 모델의 텍스트 및 이미지 입력 처리와 최대 128k 토큰 지원

1.2 API 키 발급 및 보안 설정

- OpenAI 계정의 API Keys 페이지 내 신규 비밀 키 생성
- 발급받은 API 키의 비밀 유지 및 소스 코드/공개 저장소 노출 방지
- 소스 코드 내 하드코딩 방지 및 환경 변수(.env 파일) 활용 관리
- python-dotenv 라이브러리를 통한 .env 파일 환경 변수 로드
- os.getenv('OPENAI_API_KEY')[:3] 구문을 통한 API 키 정상 로드 검증

- 구글 코랩(Colab) 환경 활용 시 보안 비밀 키(secrets) 등록 및 userdata.get('OPENAI_API_KEY') 호출 사용

- 추론 모델 및 비추론 모델의 특징 및 분류
	- 추론 모델 : o 시리즈(o1, o3, o3-mini), GPT-5 시리즈(gpt-5, gpt-5-mini, gpt-5-nano)
		* 일반 비추론 모델 대비 토큰 사용량 증가
	- 비추론 모델 : GPT-4 시리즈 이하(gpt-4o, gpt-4.1), Claude 3.5 Sonnet, Gemini 1.5 Flash

	ex)
	import os
	from dotenv import load_dotenv
	from openai import OpenAI

	# 환경 변수 로드 및 API 키 확인
	load_dotenv()
	print(os.getenv('OPENAI_API_KEY')[:3])

	# OpenAI 파이썬 클라이언트 인스턴스 생성
	client = OpenAI()

	# 기본 response 생성 요청 (gpt-4o-mini)
	response = client.responses.create(
		model="gpt-4o-mini",
		input="What is gpt?"
	)

	print(response.output_text)
	print(response.output[0].content[0].text)
	print(response.usage)

	# 한국어 텍스트 요청
	response = client.responses.create(
		model="gpt-4o-mini",
		input="gpt가 뭐야?"
	)

	print(response.output_text)

	# 추론 모델 (gpt-5-nano) 요청 (비추론 모델 대비 토큰 사용량 증가)
	response = client.responses.create(
		model="gpt-5-nano",
		input="gpt가 뭐야?"
	)

	print(response.usage)


2. 기본적인 Chat Completions API 사용법

2.1 간단한 텍스트 생성 요청

- Chat Completions 엔드포인트 : 메시지 목록을 입력받아 다음 대화 메시지 생성

- 역할(role) 및 주요 메시지 구성 요소
	- user : 사용자 입력 메시지
	- assistant : 모델의 응답 메시지
	- system : 모델의 역할 및 행동 지침 메시지
- 비추론 모델 주요 매개변수
	- temperature : 창의성 조절 (0.0 ~ 2.0 사이 설정)
	- frequency_penalty : 동일 단어 반복 빈도 제어 (-2.0 ~ 2.0 사이 설정)
- 추론 모델 주요 매개변수
	- reasoning_effort : 추론 깊이 조절 (minimal, low, medium, high 선택)
- Few-shot 프롬프트 기법
	- 대화 예시를 메시지 목록에 직접 포함하여 원하는 응답 양식 학습
	- 입력 예시 증가에 따른 input token 사용량 증가 유의

2.2 Client와 대화 연속성 및 응답 활용

- OpenAI API의 무상태(Stateless) 동작 방식 및 이전 대화 기록 미저장 특징
- 이전 대화 기억을 위한 response 답변의 messages 리스트 누적 재전달 필요성
- 페르소나 설정을 통한 시스템 역할 지정 및 대화 맥락 제어 (컴퓨터 전문가, 문학 전문가 등)
- JSON 형식 출력 활용
	- response_format={'type': 'json_object'} 옵션을 통한 JSON 객체 형태 응답 수신
	- 프롬프트 내 JSON 단어 명시적 포함 필요
	- json.loads() 함수를 활용한 파이썬 데이터 구조 변환
- 웹 및 외부 활용을 위한 askGPT 요약 함수 구현

	ex)
	import json
	from dotenv import load_dotenv
	from openai import OpenAI

	client = OpenAI()

	# 비추론 모델 사용자 메시지 요청
	messages = [
		{'role': 'user', 'content': '안녕하세요. 오늘 날씨가 어떤가요?'}
	]

	response = client.chat.completions.create(
		model='gpt-4.1-nano',
		messages=messages,
		temperature=0.7,
		frequency_penalty=0.5
	)
	print(response.choices[0].message.content)

	# 추론 모델 사용자 메시지 요청
	response = client.chat.completions.create(
		model='gpt-5-nano',
		messages=messages,
		reasoning_effort='minimal'
	)
	print(response.choices[0].message.content)

	# 비추론 모델 Few-shot 예시 적용 (input token 사용량 증가 유의)
	response = client.chat.completions.create(
		model='gpt-4.1-nano',
		messages=[
			{'role': 'system', 'content': '친절하게 답변해주는 비서'},
			{'role': 'user', 'content': '프랑스의 수도는?'},
			{'role': 'assistant', 'content': '파리(수도명만 대답)'},
			{'role': 'user', 'content': '이탈리아의 수도는 어디야?'},
			{'role': 'assistant', 'content': '로마(수도명만 대답)'},
			{'role': 'user', 'content': '한국의 수도는?'}
		]
	)
	print(response.choices[0].message.content)

	# 페르소나 설정 예시 1 (컴퓨터 프로그램 전문가)
	response = client.chat.completions.create(
		model='gpt-4.1-nano',
		messages=[
			{'role': 'system', 'content': '너는 컴퓨터 프로그램 전문가야'},
			{'role': 'user', 'content': 'Spring이 뭐야?'}
		],
		temperature=0.7,
		frequency_penalty=0.5
	)
	print(response.choices[0].message.content)

	# 페르소나 설정 예시 2 (문학 전문가)
	response = client.chat.completions.create(
		model='gpt-4.1-nano',
		messages=[
			{'role': 'system', 'content': '너는 시를 좋아하는 문학 전문가야'},
			{'role': 'user', 'content': 'Spring이 뭐야?'}
		],
		temperature=0.7,
		frequency_penalty=0.5
	)
	print(response.choices[0].message.content)

	# 대화 기록 전달을 통한 연속성 유지 예시
	response = client.chat.completions.create(
		model='gpt-4.1-nano',
		messages=[
			{'role': 'system', 'content': '너는 친절하지만 짧게 대답해주는 비서야'},
			{'role': 'user', 'content': '2020년 월드시리즈 누가 우승했어?'},
			{'role': 'assistant', 'content': '2020년 월드시리즈는 로스앤젤레스 다저스가 우승했어요.'},
			{'role': 'user', 'content': '점수와 상대 팀은?'}
		],
		temperature=1,
		frequency_penalty=0.5
	)
	print(response.choices[0].message.content)

	# JSON 형식 응답 요청
	response = client.chat.completions.create(
		model='gpt-4.1-nano',
		messages=[
			{'role': 'system', 'content': '너는 친절하지만 짧게 대답해주는 비서야, JSON으로 출력해줘'},
			{'role': 'user', 'content': '2020년 월드시리즈 누가 우승했어?'}
		],
		response_format={'type': 'json_object'},
		temperature=1,
		frequency_penalty=0.5
	)

	json_string = response.choices[0].message.content
	print(json_string)

	# JSON 문자열을 파이썬 데이터로 변환
	data = json.loads(json_string)
	print(data)

	# 웹 및 외부 활용을 위한 함수화
	def askGPT(prompt):
		load_dotenv()
		client = OpenAI()
		response = client.chat.completions.create(
			model='gpt-4.1-nano',
			messages=[
				{'role': 'system', 'content': '당신은 텍스트를 요약하는 어시스턴트 입니다.'},
				{'role': 'user', 'content': f'your task is to summarize the text sentences in korean language. Summarize in 2 lines. Use the format of a check(✅). text : {prompt}'}
			]
		)
		return response.choices[0].message.content


3. 스트리밍 응답 (Streaming)

3.1 스트리밍 활용 필요성

- 실시간 피드백 제공을 통한 사용자 경험 개선
- 긴 응답의 토큰 단위 수신을 통한 메모리 사용 효율화
- 응답 수신 중 UI 업데이트 및 기타 이벤트 동시 처리 가능성

3.2 스트리밍 구현 방법

- stream=True 옵션 설정을 통한 이터레이터(iterator) 반환
- for 문 순회를 통한 부분 응답(chunk) 수신 및 chunk.choices[0].delta.content 속성 추출
- time.sleep() 연동을 통한 출력 속도 제어 예시

	ex)
	import time
	from openai import OpenAI

	client = OpenAI()

	messages = [
		{'role': 'system', 'content': '대한민국을 사랑하는 도우미 입니다. 대한민국의 도시 이름만 한글자씩 출력하세요'},
		{'role': 'user', 'content': '도시명 5개 알려줘'}
	]

	# 스트리밍 응답 순회 및 chunk 수신
	for chunk in client.chat.completions.create(
		model='gpt-4.1-nano',
		messages=messages,
		stream=True
	):
		chunk_msg = chunk.choices[0].delta.content
		if chunk_msg:
			print(chunk_msg, end='/')
			time.sleep(0.5)


4. 시스템 메시지 활용

- 시스템 메시지(system role message)의 역할 및 특징
	- 전체 대화의 맥락, 행동 규칙, 응답 양식 사전 지정
	- 사용자 비노출 및 모델에 대한 강력한 지침 작용

- 주요 활용 목적
	- 행동 지침 부여 : 따라야 할 규칙 및 제한 설정 (예: 반말 금지, 이모티콘 포함 지침)
	- 역할(페르소나) 부여 : 특정 인격 및 전문가 역할 설정 (예: 역사 전문가, 비서, 해적, 할머니 등)
	- 컨텍스트 설정 : 대화 주제 및 환경 사전 정의 (예: 의료 상담, 프로그래밍 지원)

	ex)
	from openai import OpenAI
	client = OpenAI()

	# 해적 말투 코딩 어시스턴트 설정
	messages_pirate = [

		{'role': 'user', 'content': 'Python에서 객체가 특정 클래스의 인스턴스인지 확인하려면 어떻게 하는지 한국어로 설명해줘.'}
	]

	response = client.chat.completions.create(
		model='gpt-4.1-nano',
		messages=messages_pirate,
		temperature=1,
		frequency_penalty=0.5
	)
	print(response.choices[0].message.content)

	# 할머니 말투 코딩 어시스턴트 설정
	messages_grandma = [
		{'role': 'system', 'content': 'You are a coding assistant that talks like a grandma'},
		{'role': 'user', 'content': 'Python에서 객체가 특정 클래스의 인스턴스인지 확인하려면 어떻게 하는지 한국어로 설명해줘.'}
	]

	response = client.chat.completions.create(
		model='gpt-4.1-nano',
		messages=messages_grandma,
		temperature=1,
		frequency_penalty=0.5
	)
	print(response.choices[0].message.content)


5. 고급 활용법

5.1 토큰 최적화 및 비용 절감

- OpenAI API의 토큰 단위 비용 청구 방식

- 주요 토큰 최적화 전략
	- 짧고 명확한 프롬프트 작성을 통한 입력 토큰 절감
	- 이전 대화 기록의 핵심 요약 및 선택적 포함을 통한 맥락 관리
	- 단순 작업에 대한 경량 모델(gpt-4.1-nano 등) 활용
	- max_tokens 파라미터를 활용한 응답 최대 길이 제어
	- Batch API 활용을 통한 다수 요청 비동기 일괄 처리 및 비용 절감

- 토큰 사용량 측정
	- response.usage 객체 조회를 통한 prompt_tokens, completion_tokens, total_tokens 확인

5.2 에러 핸들링 및 예외 처리

- 주요 에러 유형 및 대처 방안
	- 네트워크 오류 및 타임아웃 : 지수적 지연 전략(exponential backoff) 및 재시도 적용
	- RateLimitError : 허용 요청량 초과 시 대기 및 요청 빈도 조절
	- InvalidRequestError : 모델명, 매개변수 규격, 입력 형식 사전 검증
	- AuthenticationError : API 키 유효성 및 권한 상태 검증

- 파이썬 라이브러리 예외 구조
	- 최상위 부모 예외 클래스 : openai.OpenAIError
	- 세부 예외 클래스의 OpenAIError 상속 구조
	
	ex)
	import openai
	from openai import OpenAI

	client = OpenAI()

	# 토큰 사용량 측정 예시
	response = client.chat.completions.create(
		model='gpt-4.1-nano',
		messages=[{'role': 'user', 'content': '토큰 사용량 확인'}]
	)

	print('입력 토큰 수:', response.usage.prompt_tokens)
	print('출력 토큰 수:', response.usage.completion_tokens)
	print('총 토큰 수:', response.usage.total_tokens)

	# 타임아웃 예외 처리 예시 (OpenAIError 상속 구조 활용)
	try:
		res = client.chat.completions.create(
			model='gpt-4.1-nano',
			messages=[{'role': 'user', 'content': '에러 발생시키기'}],
			timeout=0.01
		)
	except openai.OpenAIError as e:
		print('요청 시간을 초과하였습니다.')
		print(e)
		print(type(e))
