3장. JOIN문
- 2개 이상의 테이블을 연결하여 데이터를 검색하는 방법

	ex) CROSS JOIN
	-- 조인 조건이 없거나 잘못 지정된 경우 (EMP 14행 * DEPT 4행 = 56행 도출)
	SELECT * FROM EMP, DEPT;


1. INNER JOIN
- 조건에 일치하는 행만 추출하는 조인 방식

1.1 EQUI JOIN
- 두 테이블에서 공통으로 존재하는 필드의 값이 일치(=)하는 행을 연결
- 테이블 별칭 지정 시 AS와 ""를 사용하지 않음
- 두 테이블에 동일한 필드명이 존재할 경우 반드시 테이블명(또는 별칭)을 명시

	ex)
	SELECT ENAME, JOB, E.DEPTNO, LOC, DNAME 
		FROM EMP E, DEPT D 
		WHERE E.DEPTNO = D.DEPTNO;

	ex) 급여가 2000 이상인 직원의 이름, 직급, 급여, 부서명, 위치
	SELECT ENAME, JOB, SAL, DNAME, LOC 
		FROM EMP E, DEPT D 
		WHERE E.DEPTNO = D.DEPTNO AND SAL >= 2000;

	ex) 상여금을 받은, 급여가 1200 이상인 직원의 이름, 급여, 부서번호, 부서명, 상여금
	SELECT ENAME, SAL, E.DEPTNO, DNAME, COMM
		FROM EMP E, DEPT D
		WHERE E.DEPTNO = D.DEPTNO AND COMM IS NOT NULL AND COMM != 0 AND SAL >= 1200;

1.2 NON-EQUI JOIN
- 등가 연산자(=)가 아닌 연산자(BETWEEN ~ AND, >, < 등)를 사용하여 행을 연결

	ex) 전체 직원의 급여 등급 확인
	SELECT ENAME, JOB, SAL, GRADE 
		FROM EMP, SALGRADE 
		WHERE SAL BETWEEN LOSAL AND HISAL;

	ex) 모든 사원의 사번, 이름, 직급, 상사 사번, 급여, 급여 등급(N등급)
	SELECT EMPNO, ENAME, JOB, MGR, SAL, GRADE || '등급' AS GRADE
		FROM EMP, SALGRADE
		WHERE SAL BETWEEN LOSAL AND HISAL;

1.3 SELF-JOIN
- 하나의 테이블 내부의 연관 데이터 연결
- 한 테이블에 서로 다른 2개 이상의 별칭을 부여

	ex) 모든 사원의 사번, 이름, 상사 사번, 상사 이름 (상사가 없는 KING은 제외)
	SELECT E.EMPNO, E.ENAME, E.MGR, M.ENAME MNAME
		FROM EMP E, EMP M
		WHERE E.MGR = M.EMPNO
		ORDER BY MNAME;

	ex) 문자열 연결 연산자와의 활용
	SELECT E.ENAME || '의 상사는 ' || M.ENAME || '다' AS "직원-상사"
		FROM EMP E, EMP M
		WHERE E.MGR = M.EMPNO;


2. OUTER JOIN
- 조인 조건에 맞지 않아 누락되는 행(매칭 데이터가 없는 행)까지 결과 집합에 포함
- 데이터가 부족하여 NULL로 채워져야 하는 쪽의 조건절 컬럼에 (+) 기호를 붙임

2.1 SELF-JOIN에서의 OUTER JOIN

	ex) 모든 사원의 이름, 상사 사번, 상사 이름 (상사가 없는 KING 포함)
	SELECT W.ENAME, W.MGR, M.EMPNO, M.ENAME
		FROM EMP W, EMP M
		WHERE W.MGR = M.EMPNO(+);

	ex) 말단 사원(상사 역할로 존재하지 않는 사원)의 사번, 이름
	SELECT M.EMPNO, M.ENAME
		FROM EMP W, EMP M
		WHERE W.MGR(+) = M.EMPNO AND W.MGR IS NULL;

2.2 EQUI-JOIN에서의 OUTER JOIN

	ex) 사원이 배치되지 않은 부서(40번 부서) 정보까지 포함하여 출력
	SELECT * 
		FROM EMP E, DEPT D
		WHERE E.DEPTNO(+) = D.DEPTNO;
