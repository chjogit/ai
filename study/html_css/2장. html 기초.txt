2장. html 기초

1. 태그(Tag)

- 웹문서(HTML)를 구성하는 기본 요소
- W3C 재단에서 미리 정의한 규격을 사용함
- 기본 구조 : 열린 태그, 닫힌 태그, 태그 이름, 속성(Attribute), 속성값(Value)
- 대부분 쌍으로 존재하지만, 닫힌 태그가 없는 단일 태그(예: <img />, <br />)도 존재함

	ex) 기본 태그 구조
	<!DOCTYPE html>
	<html lang="en">
	<head>
		<meta charset="utf-8" />
		<title>태그 예제</title>
		<style>
			body { background-color: #fff000; }
		</style>
	</head>
	<body>
		<!-- 태그 이름: a, 속성: href, 속성값: http://www.daum.net -->
		<a href="http://www.daum.net">
			<img src="img/parkseyoung.jpg" alt="다음" />
		</a>
	</body>
	</html>

2. HTML5 기본 구조

2-1. <!DOCTYPE html>

- 문서의 가장 첫 줄에 위치해야 함
- 웹 브라우저가 현재 웹 페이지를 HTML5 문서로 인식하도록 지정하는 필수 선언문

2-2. <html lang="ko">

- HTML 문서의 시작과 끝을 감싸는 최상위 태그
- lang 속성 : 검색 엔진이 웹 페이지의 언어를 쉽게 인식하도록 설정 (ko: 한국어, en: 영어, ja: 일본어 등)

2-3. <head> ... </head>

- 문서의 정보 및 설정값(CSS, JavaScript)을 포함하는 영역
- <head> 내부에 사용할 수 있는 주요 태그
	- <meta> : 웹 페이지 추가 정보(인코딩, 키워드 등) 전달
	- <title> : 웹 페이지 제목 표시줄 텍스트
	- <script> : JavaScript 추가
	- <link> : 외부 파일(CSS 스타일시트 등) 연결
	- <style> : 내부 CSS 스타일 작성

2-4. <body> ... </body>

- 실제 출력되는 정보를 작성하는 영역


3. 글자 관련 태그

- <h1> ~ <h6> : 제목(Header) 태그 (줄바꿈 포함, 숫자가 작을수록 큼)
- <p> : 본문 단락 태그 (기본 폰트 크기: 16px, 줄바꿈 포함)
- <br /> : 줄바꿈 태그
- <hr /> : 수평 구분선 태그
- <a href="URL">: 하이퍼링크(Anchor) 태그
	* target="_blank" : 새 창/새 탭에서 열기
	* href="#id" : 페이지 내부 특정 위치로 이동
- <b> / <i> : 글자 굵게(Bold) / 기울임체(Italic)
- <sup> / <sub> : 위 첨자 / 아래 첨자
- <del> : 취소선(Delete)
- <pre> : 작성한 텍스트의 공백과 줄바꿈을 그대로 화면에 표시하는 태그

	ex) 글자 관련 태그 예제
	<body>
    		<h1 id="top">H1 태그 : 제목 태그 - 자동 개행 및 마진(바깥 여백) 생성</h1>
    		<h2>H2 태그 : 제목 태그</h2>
    		<h3>H3 태그 : 제목 태그</h3>
    		<h7>H 태그는 H6까지 존재. <br />
    		존재하지 않는 태그는 패스함.</h7><br />
                         <WEB>
                             <!-- <>가 있을 경우 무조건 태그로 인식함-->
                             &lt;WEB&gt:

                             <p>
                                 P 태그 : 단락 태그 <br />
                                 P 태그가 닫히면 자동으로 개행되고
                                 다음 단락까지 마진이 생김.
                             </p>
                             <h1><i> i 태그 : 기울여서 What is Lorem Ipsum?</i></h1>
                             <p>
                                 'Lorm Ipsum'
                             </p>
                             <h1><b> b 태그 : 진하게 한글 입숨</b></h1>
                             <p>
                                 '한글 입숨'
                             </p>
                             <h2 align="center"> align = center </h2>
                             <h2><strong> strong 태그 : 진하게</strong></h2>
                             <h2>글자<sub> sub 태그 : 아랫 첨자</sub></h2>
                             <h2>글자<sup> sup 태그 : 윗 첨자</sup></h2>
                             <h2>글자<ins> ins 태그 : 언더 라인</ins></h2>
                             <h2>글자<del> del 태그 : 제거 라인</del></h2>

                             <h1><del>20,000원</del> →<b>10,000원(<span>50% 할인</span>)</b></h1>
                             <a href="#top"> 맨 위로 </a> <!-- #id로 이동 -->
	</body>
	</html>

4. 목록(List) 태그

- <ul> : 순서가 없는 목록 (Unordered List)
	type 속성: disc(기본 검은 원), circle(흰 원), square(사각형)

- <ol> : 순서가 있는 목록 (Ordered List)
	type  : 1(숫자), a/A(영문 소문자/대문자), i/I(로마 숫자)
	start  : 시작 번호 지정

- <li> : 목록 항목 (List Item)

	ex) 목록 태그 예제
	<!DOCTYPE html>
	<html lang="en">
	<head>
		<meta charset="utf-8" />
		<title>목록 태그</title>
	</head>
	<body>
		<p>순서 없는 메뉴 리스트</p>
		<ul type="square">
			<li>menu1</li>
			<li>menu2</li>
		</ul>

		<p>순서 있는 리스트</p>
		<ol type="a" start="2">
			<li>순서 b부터 시작</li>
			<li>순서 c</li>
		</ol>
	</body>
	</html>

5. 표(Table) 태그

- 표 형식의 레이아웃, 회원가입/로그인 폼, 게시판 목록 등에 사용
- <table> : 표 전체를 감싸는 태그
- <tr> : 표의 행
- <th> : 표의 제목 셀(기본 굵게+중앙정렬)
- <td> : 표의 일반 데이터 셀
- <thead> / <tbody> / <tfoot> : 표의 구조 분할 (제목/본문/하단)
- rowspan : 행 병합 (세로 합치기)
- colspan : 열 병합 (가로 합치기)

	ex 1) 표 태그 예제
	<!DOCTYPE html>
	<html lang="en">
	<head>
		<meta charset="utf-8" />
		<title>표 태그</title>
	</head>
	<body>
		<table border="1">
			<caption>표 제목</caption>
			<tr>
				<td rowspan="3">1행 1열 (3행 병합)</td>
				<td>1행 2열</td>
				<td>1행 3열</td>
			</tr>
			<tr>
				<td>2행 2열</td>
				<td>2행 3열</td>
			</tr>
			<tr>
				<td>3행 2열</td>
				<td>3행 3열</td>
			</tr>
		</table>
	</body>
	</html>

6. 이미지 출력 태그 - <img>

- src : 이미지 파일 경로 지정 (상대경로 또는 웹 URL)
- alt : 이미지를 불러오지 못할 때 대체 출력될 텍스트
- width / height : 이미지의 너비와 높이 지정 (최근에는 CSS에서 스타일을 설정하는 것을 권장)

	ex) 이미지 태그 예제
	<!DOCTYPE html>
	<html lang="en">
	<head>
		<meta charset="utf-8" />
		<title>이미지 태그</title>
	</head>
	<body>
		<p><img src="img/psy.jpg" alt="박세영"></p>
		<p><img src="img/sulhyun.jpg" alt="설현" width="50" height="100"></p>
		<p><img src="http://example.com/image.jpg" alt="웹 이미지"></p>
	</body>
	</html>

7. 오디오 태그 - <audio> (HTML5 추가)
- 외부 플러그인 없이 웹 브라우저에서 사운드를 재생하는 태그
- 주요 속성 :
	src : 오디오 파일 경로 지정
	controls : 재생/일시정지 등 오디오 제어기 표시
	autoplay : 자동 재생 여부 (브라우저 정책에 따라 제한될 수 있음)
	loop : 반복 재생 여부
	preload : 페이지를 로드할 때 오디오 파일을 미리 불러올지 여부 (auto, metadata, none)

ex) 오디오 태그 예제
	<!DOCTYPE html>
	<html lang="en">
	<head>
		<meta charset="utf-8" />
		<title>오디오 태그</title>
	</head>
	<body>
		<h3>단일 src 속성 방식</h3>
		<audio src="sound/stevejobs1.mp3" preload="auto" controls loop></audio>

		<h3><source> 태그 분리 방식</h3>
		<audio controls loop>
			<source src="sound/stevejobs2.mp3" type="audio/mpeg" />
		</audio>
	</body>
	</html>
