7장. 규칙과 반응형 웹

1. CSS3 규칙

1-1. CSS 파일 분리

- HTML 문서 내부의 스타일을 외부 CSS 파일(.css)로 분리하여 불러오는 방식
- 코드의 재사용성 향상 및 유지보수 용이

	ex)
	<link rel="stylesheet" href="initialcode.css" />
	<link rel="stylesheet" href="header.css" />

1-2. @import 규칙

- CSS 파일 내부 또는 HTML의 <style> 태그 내에서 다른 외부 CSS 파일을 불러오는 규칙입니다.
- 주요 특징 및 제한 사항
  * <link> 태그 대신 외부 CSS를 불러올 때 사용 가능
  * 반드시 <style> 태그 내부 또는 CSS 파일 내에 위치해야 함
  * 다른 일반 CSS 스타일 규칙보다 **최상단(맨 위)**에 위치해야 작동함

	ex)
	<style>
	    @import url('title.css');
	    
	    /* 스타일 규칙은 @import보다 아래에 작성 */
	    body { margin: 0; }
	</style>

1-3. @media 규칙 및 미디어 타입

- 미디어 타입 및 화면 조건에 따라 서로 다른 CSS 스타일을 적용하도록 설정하는 규칙입니다.
- <link> 태그의 media 속성으로 파일 단위 분리가 가능하며, CSS 내부에서 @media 구문으로 지정할 수도 있습니다.
- 주요 미디어 타입:
  * all : 모든 미디어 기기 대상 (기본값)
  * screen : 컴퓨터, 스마트폰, 태블릿 등의 화면 스크린 대상
  * print : 인쇄 장치 및 인쇄 미리보기 화면 대상

	ex 1) <link> 태그의 media 속성 활용
	<!DOCTYPE html>
	<html lang="en" xmlns="http://www.w3.org/1999/xhtml">
	<head>
	    <meta charset="utf-8" />
	    <title>Media Query Link Example</title>
	    <style type="text/css">
	        * { margin:0; padding:0; }
	        #wrap { width:800px; margin:0 auto; border:1px solid #cccccc; padding:10px; }
	        #hr { margin:10px 0; }
	    </style>
	    <link rel="stylesheet" href="css/title.css" />
	    <link rel="stylesheet" href="css/content-pc.css" media="screen" />
	    <link rel="stylesheet" href="css/content-print.css" media="print" />
	    <link rel="stylesheet" href="css/date.css" />
	</head>
	<body>
	    <div id="wrap">
	        <div class="title">
	            <h1>NOTICE</h1>
	        </div>
	        <hr />
	        <div class="content">
	            <p>Lorem Ipsum is simply dummy text of the printing and typesetting industry.</p>
	        </div>
	        <div class="date">
	            <p>2026. 08.04<br />written by Hong Gil-Dong</p>
	        </div>
	    </div>
	</body>
	</html>

	ex 2) <style> 태그 내부 @media 구문 활용
	<style>
	    /* 모니터 화면 출력용 스타일 */
	    @media screen {
	        #wrap .content {
	            background-color: darkgreen;
	            color: white;
	            padding: 30px 10px;
	        }
	    }

	    /* 인쇄 시 적용되는 스타일 */
	    @media print {
	        #wrap .content {
	            background-color: transparent;
	            color: black;
	            padding: 30px 10px;
	        }
	    }
	</style>

2. 반응형 웹 (Responsive Web Design)

- 단일 HTML 소스코드로 디바이스 해상도(Screen Size) 변화에 맞춰 뷰포트를 유동적으로 재구성하는 기법
- 동일한 HTML 소스를 유지한 상태로 화면 환경(Viewport 및 Media Query)에 맞게 최적화된 출력을 제공

	ex)
        @media screen and (max-device-width:959px) {
            #wrap { width: 100%;background-color: lightyellow;}
            #wrap #nav ul li:last-child{display:none;}
            #wrap #nav ul li{width:25%;}
            #wrap #content p {font-size:1.5em;}
        }
        @media screen and (min-device-width:960px) and (max-device-width:1201px){
            #wrap { width:100%; background-color:aqua;
                    opacity:0.8;       }
            #wrap #nav ul li{width:20%;}
        }
        @media screen and (min-device-width:1201px){
            #wrap {width:800px; }
            #wrap #content {background-color:coral;}
            #wrap #nav ul li{width:20%;}
