4장. CSS 선택자

- 선택자
	- HTML 문서 내에서 특정 요소를 지정하여 원하는 CSS 스타일을 적용하는 문법
	- CSS 외에도 JavaScript(querySelector), jQuery 등에서 사용

1. 기본 선택자 (태그 선택자 & 쉼표 그룹화)

	- 특정 태그 전체에 스타일을 적용하거나, 쉼표(,)를 사용해 여러 선택자를 그룹으로 묶어 동일한 스타일을 한 번에 적용

	ex)
		<!DOCTYPE html>
		<html lang="en" xmlns="http://www.w3.org/1999/xhtml">
		<head>
		    <meta charset="utf-8" />
		    <title></title>
		    <style>
		        header, footer{color:blue; border:1px solid gray;/*위우하좌*/}
		        h1{border:1px dashed red;}
		        li, p {color:red;/*글씨색*/ background-color:pink; font-weight:bold;/*글씨굵게*/ }
		        p{color:chocolate;}
		    </style>
		</head>

2. 전체 선택자 (*)

	- 문서 내의 모든 요소(HTML 모든 태그) 일괄 선택
	- 주로 브라우저별 기본 여백(margin, padding)을 제거하는 등 초기화(Reset) 목적으로 사용

	ex)
		<!DOCTYPE html>
		<html lang="en" xmlns="http://www.w3.org/1999/xhtml">
		<head>
		    <meta charset="utf-8" />
		    <title></title>
		    <style>
		        * { /* 페이지 디자인 초기화할 때 */
		            color:blue; padding:0; /*안여백*/ margin:0; /*밖여백*/
		        }
		        p{color:chocolate; } /* 각 선택자에 대한 디자인은 밑부분에*/
		        ul{overflow:hidden;}
		        li{float:left; list-style:none;margin:10px;}
		        section{clear:both;}
		    </style>
		</head>

3. id 선택자(#)와 class 선택자(.)

	- id 선택자 (#)
		- 문서 내에서 고유하게 단 하나만 존재하는 요소에 지정할 때 사용합니다. (우선순위가 높음)

	- class 선택자 (.)
		- 재사용을 목적으로 여러 요소에 동시 지정하여 공통 스타일을 적용할 때 사용합니다.

	ex)
		<!DOCTYPE html>
		<html lang="en" xmlns="http://www.w3.org/1999/xhtml">
		<head>
		    <meta charset="utf-8" />
		    <title></title>
		    <style>
		        div{border:1px solid gray;}
		        #header{
		            width:600px; margin:0 auto;
		            background-color:yellow;
		            text-align:center; /* 가운데 정렬 */
		        }
		        #wrap{
		            width:600px; margin: 0 auto;
		            background-color:aqua;
		            overflow:hidden;
		        }
		        #content{
		            width:350px; /* #content가 필요한 영역=width(350)+border(2)=352px;*/
		            float:left;
		            text-align:center;
		            height:250px;
		        }
		        #side_banner{
		            width:246px; /* #side_banner가 필요한 영역 = 246+2 = 248px*/
		            float:right;
		            text-align:center;
		            height:250px;
		        }
		        img{width:200px;}
		        .menu1 {
		            font-size: 1.5em; /*원크기의 1.2배*/
		        }
		        li.menu2, .menu4{font-weight:bold; /*글씨 진하게*/}
		        #footer{
		            clear:both;
		            width:600px; margin:0 auto;
		            background-color:yellow;
		            text-align:center; /* 가운데 정렬 */
		        }
		    </style>
		</head>

4. tag, id, class 혼합 선택자

		    <meta charset="utf-8" />
		    <title></title>
		    <style>
		        div{border:1px solid gray;}
		        #header{
		            width:600px; margin:0 auto;
		            background-color:yellow;
		            text-align:center; /* 가운데 정렬 */
		        }
		        #wrap{
		            width:600px; margin: 0 auto;
		            background-color:aqua;
		            overflow:hidden;
		        }
		        #content{
		            width:350px; /* #content가 필요한 영역=width(350)+border(2)=352px;*/
		            float:left;
		            text-align:center;
		            height:250px;
		        }
		        #side_banner{
		            width:246px; /* #side_banner가 필요한 영역 = 246+2 = 248px*/

5. 속성 선택자 (Attribute Selectors)

	- HTML 태그 내부의 속성값 유무나 패턴에 따라 요소를 선택
	- 문법 종류
		- 선택자[속성] : 해당 속성을 가지고 있는 모든 요소 선택
		- 선택자[속성=값] : 속성 값이 정확히 일치하는 요소 선택
		- 선택자[속성^=값] : 속성 값이 특정 문자열로 시작하는 요소 선택
		- 선택자[속성$=값] : 속성 값이 특정 문자열로 끝나는 요소 선택

	ex)
		<!DOCTYPE html>
		<html lang="en" xmlns="http://www.w3.org/1999/xhtml">
		<head>
		    <meta charset="utf-8" />
		    <title></title>
		    <style>
		        #header{
		            color:orange;
		            text-align:center;
		            width:350px;
		            margin:0 auto;
		        }
		        #section {
		            width: 350px;
		            margin: 50px auto;
		            padding:20px;
		            border-top: 1px solid gray;
		            border-bottom: 1px solid gray;
		        }
		        #section h4[title^='남자'] {
		            background: url(man.png) no-repeat;
		            padding: 0px 30px;
		        }
		        #section h4[title^='여자'] {
		            background: url(woman.png) no-repeat;
		            padding: 0px 30px;
		         }
		        a { text-decoration:none;}
		        #section a[href $= "docx"]{
		            background:url(word.png) center right no-repeat;
		            padding: 0 25px;
		        }
		        #section a[href $= "xlsx"]{
		            background:url(excel.png) center right no-repeat;
		            padding: 0 25px;
		        }
		        #footer {
		            width: 350px;
		            margin: 0 auto;
		            color: gray;
		        }
		    </style>
		</head>

6. 후손 / 자손 선택자

	- 후손 선택자 (공백) : 기준 요소 '내부에 포함된 모든' 지정 요소를 깊이에 상관없이 선택 (자식, 손자 등 전체)
	- 자손 선택자 (>) : 기준 요소 바로 한 단계 아래에 있는 '직계 자식' 요소만을 선택

	ex)
		<!DOCTYPE html>
		<html lang="en" xmlns="http://www.w3.org/1999/xhtml">
		<head>
		    <meta charset="utf-8" />
		    <title></title>
		    <style>
		        #header, #wrap, #footer{
		            border: 1px solid #cccccc; width:700px; margin:0 auto;
		        }
		        div li{ /* 후손 선택자 */
		            background-color:red;
		        }
		        div p{ /* 후손 선택자 */
		            font-weight:bold; font-size:25pt;
		        }
		        div > p{ /* 자손 선택자 */
		            color:blue;
		        }
		    </style>
		</head>
		<body>
		    <div id="header"> ; 자손(자식), 후손
		        <div class="logo">
		            <h1>LOGO</h1>
		        </div>
		</body>
		</html>

7. 동위(형제) 선택자 (+ / ~)

	- 동일한 부모 요소를 공유하는 형제 관계의 태그 선택

		- + 선택자 : 기준 요소 '바로 뒤에 인접해 있는 형제 1개'만 선택
		- ~ 선택자 : 기준 요소 '뒤에 오는 모든 형제 요소'를 선택

	ex)
		<!DOCTYPE html>
		<html lang="en" xmlns="http://www.w3.org/1999/xhtml">
		<head>
		    <meta charset="utf-8" />
		    <title></title>
		    <style>
		        h3 ~ div { /*h3태그의 동위 선택자들 다(~)*/
		            font-size:1.3em; color:orange; font-weight:bold;
		        }
		        h3 + div{ /* h3태그의 동위선택자들 중 바로 다음 것*/
		            color:red;
		        }
		    </style>
		</head>

8. 반응 가상 클래스 선택자 (hover 등)

	- 사용자의 동작(마우스 커서 올리기 등)에 반응하여 스타일을 동적으로 변경

		- hover : 요소 위에 마우스 커서가 올라가 있을 때 적용됩니다.

	ex)
		<!DOCTYPE html>
		<html lang="en" xmlns="http://www.w3.org/1999/xhtml">
		<head>
		    <meta charset="utf-8" />
		    <title></title>
		    <style>
		        div{width:300px; margin:0 auto; background-color:red;}
		        ul > li{font-size:32px; color:white;}
		        li:hover{ /* li위에 마우스를 올렸을 때 반응할 디자인 (반응선택자)*/
		           color:pink;
		           font-weight:bold; 
		        }
		    </style>
		</head>

9. 상태 가상 클래스 선택자 (focus, enabled, disabled)

	- 폼 요소(input 등)의 현재 상태에 따라 스타일 부여

		- focus : 입력창에 커서가 활성화(포커스)된 상태
		- enabled : 요소가 사용 가능한 활성화 상태
		- disabled : 요소가 비활성화(입력 불가)된 상태

	ex)
		<!DOCTYPE html>
		<html lang="en" xmlns="http://www.w3.org/1999/xhtml">
		<head>
		    <meta charset="utf-8" />
		    <title></title>
		    <style>
		        input:focus{ /*상태선택자*/
		            background-color:yellow;
		            border:1px dashed red;
		        }
		        input:disabled{color:blue;}
		        input:enabled{color:green;}
		    </style>
		</head>

10. 구조 가상 클래스 선택자 (nth-child, first-child, last-child)

	- 문서 구조상 부모 요소 내 자식들의 순서나 수식을 기반으로 요소 선택
		-  nth-child(n) : n번째 자식 선택 (예: `2n+1` 수식으로 홀수/짝수 줄무늬 표현 가능)
		-  first-child : 첫 번째 자식 선택
		-  last-child : 마지막 자식 선택

	ex)
		<!DOCTYPE html>
		<html lang="en" xmlns="http://www.w3.org/1999/xhtml">
		<head>
		    <meta charset="utf-8" />
		    <title></title>
		    <style>
		        #wrap{width:200px; margin: 0 auto;}
		        #wrap ul li{
		            list-style:none;
		            border:1px solid gray;
		            padding:10px; margin:2px;
		            text-align:center;
		            font-size:20px; font-weight:bold;
		        }
		        #wrap ul li a{
		            text-decoration:none; /* 밑줄을 없애기 */
		            color:black;
		        }
		        #wrap ul li:nth-child(2n+1){
		            background-color:orange;
		        }
		        #wrap ul li:nth-child(2n){
		            background-color:yellow;
		        }
		        #wrap ul li:first-child{
		            /*왼쪽위, 오른쪽위, 오른쪽밑, 왼쪽밑*/
		            border-radius: 20px 20px 0 0;
		        }
		        #wrap ul li:last-child{
		            border-radius:0 0 20px 20px;
		        }
		    </style>
		</head>

11. 문자 가상 요소 선택자 & 가상 요소 활용

	- 요소 내의 특정 텍스트 구간 선택 및 가상 내용 생성을 수행합니다.

		- ::first-line : 텍스트의 첫 번째 줄만 선택
		- ::first-letter : 텍스트의 첫 번째 글자만 선택
		- after (::after) : 요소의 콘텐츠 뒤에 새로운 가상 콘텐츠(content 속성)를 삽입

	ex)
		<!DOCTYPE html>
		<html lang="en" xmlns="http://www.w3.org/1999/xhtml">
		<head>
		    <meta charset="utf-8" />
		    <title></title>
		    <style type="text/css">
		        #wrap {
		            width: 500px;
		            margin: 0 auto;
		        }
		        #header {
		            border-bottom: 1px solid #cccccc;
		        }
		        #content a {
		            text-decoration:none;
		        }
		        #content a:after{
		            content: ' - ' attr(href);
		        }
		        #content li {
		            padding:2px;
		        }
		        #footer ul {
		            overflow: hidden;
		            border: 2px solid #cccccc;
		        }

		        #footer li {
		            list-style: none;
		            float: left;
		            padding: 5px;
		        }
		    </style>
		</head>


12. 부정 선택자 (not)
	
	- not(선택자) : 괄호 안에 지정한 조건(클래스, 태그 등)을 **제외한** 나머지 요소에만 스타일 적용

	ex)
		<!DOCTYPE html>

		<html lang="en" xmlns="http://www.w3.org/1999/xhtml">
		<head>
		    <meta charset="utf-8" />
		    <title></title>
		    <style>
		        #wrap {
		            width: 800px;
		            margin: 0 auto;
		        }
		        #header {
		            margin: 2px auto;
		            border-bottom: 1px solid gray;
		            text-align: center;
		        }
		        #content p:nth-child(2)::first-line, #content p:nth-child(3)::first-line { /*문자선택자*/
		            color: blue;
		            font-weight: bold; /* 진하게 */
		            font-size: 20px;
		        }

		        #content p:nth-child(2)::first-letter {
		            font-size: 2em; /*원래 크기의 2배*/
		        }

		        #content p:nth-child(3) span { /*span으로 대체 가능*/
		            font-size: 2em;
		        }
		        
		        #content a:after{ /*링크선택자*/
		            content : ' - ' attr(href);
		        }

		        #content li:not(.web) a{ /*부정선택자*/
		            padding:12px;
		            margin: 2px;
		            font-size:1.2em;
		            font-weight:bold;
		            text-align:justify;
		        }
		        #content a{
		            text-decoration:none;
		            color:black;
		         }

		        #footer ul {
		                overflow: hidden;
		                border-top: 1px solid gray;
		            }
		        #footer ul li{
		            float:left;
		            list-style:none;
		            padding:20px;   
		        }
		        #footer img {
		            height:30px;
		        }
		    </style>
		</head>
