1. 이진 분류 (Binary Classification)

- 데이터 읽기 및 전처리

	- pandas(pd.read_csv) 활용 : 결측치 확인(isna().sum()) 및 클래스 비율(value_counts()) 분석 용이
	- numpy(np.loadtxt) 활용 : 결측치가 없음이 보장된 데이터의 고속로드에 적합
	- 데이터셋 분할 : 슬라이싱 전 데이터의 정렬/편향 여부를 반드시 사전 점검

- Keras Sequential 모델 구축 및 설정

	- 입력층 : Input(shape=(8,)) - 8개의 독립변수 입력
	- 은닉층 : Dense 레이어와 relu/elu 활성화 함수 조합으로 복합 특성 추출
	- 출력층 : Dense(units=1, activation='sigmoid') - 0~1 사이의 확률값 출력
	- 컴파일 : loss='binary_crossentropy', optimizer='adam', metrics=['accuracy']

- 혼동 행렬 (Confusion Matrix) 및 성능 평가 지표

	- TN (True Negative) : 실제 0을 0으로 올바르게 예측
	- FP (False Positive) : 실제 0을 1로 잘못 예측 (1종 오류)
	- FN (False Negative) : 실제 1을 0으로 잘못 예측 (2종 오류)
	- TP (True Positive) : 실제 1을 1로 올바르게 예측

	- 정확도 (Accuracy) : 전체 데이터 중 맞춘 비율
	- 정밀도 (Precision) : 모델이 1로 예측한 것 중 실제 1인 비율
	- 재현율 (Recall) : 실제 1인 데이터 중 모델이 1로 찾아낸 비율
	- F1-Score : 정밀도와 재현율의 조화 평균

		예측: 0 			예측: 1
실제: 0  	TN (True Negative) 	FP (False Positive)
실제: 1  	FN (False Negative) 	TP (True Positive)

	ex)
	import pandas as pd
	import numpy as np
	from tensorflow.keras.models import Sequential, save_model, load_model
	from tensorflow.keras.layers import Dense, Input
	from sklearn.metrics import confusion_matrix
	import matplotlib.pyplot as plt

	# 데이터 로드 및 분할
	dataset = np.loadtxt('data/pima-indians-diabetes.csv', encoding='utf-8', delimiter=',', comments='#')
	X_train, y_train = dataset[:620, :-1], dataset[:620, -1:]
	X_test, y_test = dataset[620:, :-1], dataset[620:, -1:]

	# 모델 생성
	model = Sequential()
	model.add(Input(shape=(8,)))
	model.add(Dense(units=32, activation='elu'))
	model.add(Dense(units=64, activation='relu'))
	model.add(Dense(units=32, activation='elu'))
	model.add(Dense(units=16, activation='relu'))
	model.add(Dense(units=1, activation='sigmoid'))

	# 모델 컴파일 및 학습
	model.compile(loss='binary_crossentropy', optimizer='adam', metrics=['accuracy'])
	hist = model.fit(X_train, y_train, epochs=200, batch_size=155, validation_split=0.1, verbose=0)

	# 시각화 및 평가
	loss, accuracy = model.evaluate(X_test, y_test)
	print(f'정확도 : {accuracy*100:.2f}%')

	y_hat = (model.predict(X_test) > 0.5).astype(int)
	ctab = pd.crosstab(y_test.astype(int).reshape(-1), y_hat.reshape(-1), rownames=['실제값'], colnames=['예측값'])
	print(ctab)

	# 모델 저장 및 불러오기
	model.save('model/05_pima.h5')
	model2 = load_model('model/05_pima.h5')
	res = (model2.predict([[2, 112, 86, 42, 160, 38.4, 0.246, 28]]) > 0.5).astype(int)


2. 다중 클래스 분류 (Categorical Classification)

- 타겟 데이터 원-핫 인코딩 (One-Hot Encoding)
	- tensorflow.keras.utils.to_categorical()을 이용해 정수 라벨(0, 1)을 2차원 원-핫 벡터([1,0], [0,1])로 변환

- Keras Sequential 모델 구성 및 설정

	- 출력층 : Dense(units=2, activation='softmax') - 클래스별 확률값의 합이 1이 되도록 출력
	- 손실 함수 : loss='categorical_crossentropy' 지정 (원-핫 인코딩 라벨 필수)
	- 검증 데이터 : validation_data=(X_val, Y_val) 명시적 지정

- 예측치 추출 및 평가
	- model.predict().argmax(axis=1)을 이용하여 가장 높은 확률을 가진 클래스 인덱스 반환

	ex)
	from tensorflow.keras.utils import to_categorical

	# 데이터 로드 및 정제
	df = pd.read_csv('data/pima-indians-diabetes.csv', comment='#', header=None)
	df2 = df[df[4] != 0].reset_index(drop=True)
	dataset = df2.values

	X_train, y_train = dataset[:300, :-1], dataset[:300, -1]
	X_val, y_val = dataset[300:350, :-1], dataset[300:350, -1]
	X_test, y_test = dataset[350:, :-1], dataset[350:, -1]

	# 원-핫 인코딩
	Y_train = to_categorical(y_train, num_classes=2)
	Y_val = to_categorical(y_val, num_classes=2)
	Y_test = to_categorical(y_test, num_classes=2)

	# 모델 구축
	model = Sequential()
	model.add(Input(shape=(8,)))
	model.add(Dense(units=16, activation='relu'))
	model.add(Dense(units=32, activation='elu'))
	model.add(Dense(units=64, activation='relu'))
	model.add(Dense(units=32, activation='elu'))
	model.add(Dense(units=16, activation='relu'))
	model.add(Dense(units=2, activation='softmax'))

	# 학습 설정 및 실행
	model.compile(loss='categorical_crossentropy', optimizer='adam', metrics=['accuracy'])
	hist = model.fit(X_train, Y_train, epochs=200, validation_data=(X_val, Y_val), verbose=0)

	# 모델 평가 및 클래스 예측
	loss, accuracy = model.evaluate(X_test, Y_test)
	print(f'정확도 : {accuracy*100:.2f}%')

	y_hat = model.predict(X_test).argmax(axis=1)
	ctab = pd.crosstab(y_test.reshape(-1), y_hat.reshape(-1), rownames=['실제값'], colnames=['예측값'])
	print(ctab)

	pred_cls = model.predict([[3, 123, 100, 35, 240, 57.3, 0.88, 22]]).argmax()
