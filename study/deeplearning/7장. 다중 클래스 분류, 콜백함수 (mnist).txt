- 콜백 함수
	- 로그 출력 통제 : CustomHistory 클래스를 상속받아 1 epoch 수행 후 자동 실행되는 on_epoch_end 함수를 오버라이딩하여 특정 에포크마다 로그 출력
	- 조기 종료 (EarlyStopping) : 검증 성능(val_loss, val_accuracy 등)이 더 이상 개선되지 않을 때 학습을 중간에 중단하여 과적합 방지
	- 최적 모델 저장 (ModelCheckpoint) : 특정 시점의 모델 가중치 또는 전체 구조를 디스크에 주기적으로 저장하며 save_best_only=True 옵션 적용 가능
	- 학습률 조정 (ReduceLROnPlateau) : 모델의 성능 향상이 정체되었을 때 학습률(LR)을 자동으로 줄여서 최적점 접근 지원

	ex) 특정 에포크마다 출력하도록 로그 출력을 통제하는 Callback 클래스
	class CustomHistory(Callback):
		def __init__(self):
			self.epoch = 0

		def on_epoch_end(self, batch, logs={}):
			self.epoch += 1
			if self.epoch % 10 == 0:
				print('epoch:{}, loss:{:.4f}, acc:{:.4f}, val_loss:{:.4f}, val_acc:{:.4f}'
					.format(self.epoch,
						logs.get('loss', '-'),
						logs.get('accuracy', '-'),
						logs.get('val_loss', '-'),
						logs.get('val_accuracy', '-')
					)
				)

	ex) 조기 종료
	earlyStopping = EarlyStopping(monitor='val_accuracy',
