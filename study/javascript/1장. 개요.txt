1.1 자바스크립트의 역사

- 넷스케이프(Netscape)사에서 '모카(Mocha)'라는 이름으로 최초 개발
- 이후 썬 마이크로시스템즈의 'Java' 상표권을 활용한 마케팅 협약을 체결하였으나, 구문 및 동작 메커니즘 면에서 Java와 전혀 다른 독립적 언어임


1.2 자바스크립트의 활용

- 정적 문서(HTML)에 동적 행위(DOM 제어, 이벤트 처리)를 부여하는 클라이언트 사이드 스크립트 언어
- 웹 표준 및 네트워크 성능 향상에 따라 단순 문서 표현을 넘어 독립적인 '웹 애플리케이션'을 구동하는 핵심 엔지니어링 기술로 확장됨


1.3 HTML 내 Script 실행 순서 및 배치

- 브라우저는 HTML DOM 트리를 상단부터 순차적으로 파싱(Parsing)함
- <head> 내 스크립트는 <body> 렌더링 이전에 실행됨

	ex1) <head> 밖의 <script>
	<html lang="ko">
	<head>
    	<meta charset="utf-8" />
    	<title>DOM Manipulation</title>
    	<script>
        	document.write('<h1>첫번째 라인</h1>');
    	</script>
	</head>
	<body>
    		<h1>두번째 라인</h1>
    		<script>
        		// innerHTML을 통한 텍스트 추가
        		document.body.innerHTML += "<h2>세번째 메세지를 제목으로</h2>";
    		</script>
    		<h1>네번째 메세지 뿌린 후 제목</h1>
    		<script>
        		alert('다섯번째 메세지');
    		</script>
	</body>
	</html>

	ex2) for 문
	/* 변수 선언 시 var(전역 변수), let(지역 변수), const(상수) */
	let sum = 0;

	// for (초기화;조건;증감) {반복문}
	/* 1부터 시작하여 ; i가 5보다 작거나 같을 때까지 ; {}를 반복 실행 (i++ = i 값 1씩 증가) */
	for (var i=1 ; i<=5 ; i++) {
    		sum += i;
    	console.log('i=', i-1,'까지 누적 합 :', sum);
	}
	console.log('for문 종료');
	console.log('for문 종료 후 i값 : '+i);
