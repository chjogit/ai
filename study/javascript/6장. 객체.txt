Ch 06. 객체
- 객체의 개념 및 생성(리터럴, 생성자), 속성(Property)과 메서드(Method)
- 동적 속성 추가 및 제거(delete), `this` 키워드와 화살표 함수의 주의점
- `toString()` 메서드 오버라이딩, 객체와 배열을 활용한 데이터 관리, 객체 생성 함수(팩토리 함수)


1. 객체의 개념 및 속성 조작

- 객체 : 서로 연관된 변수(속성)와 함수(메서드)를 그룹핑하여 이름을 붙인 복합 자료형

- 객체 생성

  * 객체 리터럴 방식(주로 사용) : var obj = { key: value };
  * 객체 생성자 방식 : var obj = new Object();

- 배열과 객체의 Key 구조

  * 배열 : Key - 인덱스(0, 1, 2...)인 특수한 형태의 객체
  * 객체 : Key - 속성변수(문자열 형태의 식별자)

- 동적 속성 추가 및 삭제

  * 속성 추가 : 객체.추가할_속성명 = 값; 또는 객체['추가할_속성명'] = 값;
  * 속성 제거 : delete(객체.삭제할_속성명);

	ex) 배열과 객체의 Key 비교
		<script>
			// 배열 (Key가 numeric index)
			var arr = [1, '홍길동'];
			arr.push('새로운 값');
			arr.pop();

			document.write('<h3>배열 인덱스 확인</h3>');
			for (let idx in arr) {
				document.write(`${idx}번째(index type:${typeof(idx)}) - ${arr[idx]}<br>`);
			}

			// 객체 (Key가 속성변수)
			var obj = { 'name': '홍길동', 'age': 20 };

			// 동적 속성 추가
			obj.address = '신림동';
			obj.hobby = '노래';

			// 동적 속성 제거
			delete (obj.age);

			document.write('<h3>객체 속성 제거 후</h3>');
			for (let key in obj) {
				document.write(`${key}(key type: ${typeof(key)}) - ${obj[key]}<br>`);
			}
		</script>


2. 속성과 메서드

- 속성 : 객체 내부에 정의된 값/변수
- 메서드 : 객체의 속성 중 함수형 속성

- 메서드 정의 시 주의사항

  * 메서드 선언 시 화살표 함수 사용을 지양
  * 화살표 함수 내부의 `this`는 객체 자신을 가리키지 않고, 상위 스코프(예: window)의 `this`를 가리키기 때문

	ex) 객체의 메서드 정의
		<script>
			let person = {
				name: '홍길동',
				age: 20,
				eat: function (food) { // 일반 함수 사용 (this = person)
					alert(`${this.name}이 ${food}을(를) 먹습니다.`);
				}
			};

			person.eat('빵');

			document.write(person.name + '님<br>');
			document.write(person['name'] + '<br>');
			document.write(person.age + '세<br>');
		</script>


3. toString()
- 모든 자바스크립트 객체는 최상위 객체인 Object로부터 toString() 메서드를 상속받음
- 객체를 출력문에 전달하여 문자열로 변환할 때 자동으로 `toString()`이 호출됨
- 객체 내부에서 `toString()`을 오버라이딩하여 원하는 형태의 문자열 출력

	ex) toString() 오버라이딩
		<script>
			let person = {
				name: '홍길동',
				age: 20,
				eat: function (food) {
					let msg = `${this.age}세 ${this.name}님은 ${food}을(를) 먹습니다.`;
					document.write(msg + '<br>');
				},
				toString: function () {
					let output = '';
					for (let key in this) {
						// 메서드가 아닌 일반 속성만 출력에 포함
						if (key != 'eat' && key != 'toString') {
							output += key + ' : ' + this[key] + '<br>';
						}
					}
					return output;
				}
			};

			person.nickname = '도사';
			document.write(person); // toString()이 자동 호출되어 커스텀된 문자열 출력
		</script>


4. 객체와 배열을 활용한 데이터 관리
- 객체들을 요소로 갖는 배열을 구성하여 여러 데이터 및 공통 메서드를 일괄 관리
- 반복문을 순회하며 각 객체에 메서드를 동적으로 주입 가능

	ex) 학생 성적 데이터
		<script>
			let students = [
				{ name: '김', kor: 90, mat: 98, eng: 95 },
				{ name: '이', kor: 99, mat: 88, eng: 91 },
				{ name: '박', kor: 90, mat: 93, eng: 95 },
				{ name: '정', kor: 90, mat: 98, eng: 94 }
			];

			students.push({ name: '윤', kor: 85, mat: 78, eng: 83 });

			// 동적 메서드 주입
			for (let idx in students) {
				students[idx].getSum = function () {
					return this.kor + this.mat + this.eng;
				};

				students[idx].getAvg = function () {
					return (this.getSum() / 3).toFixed(1); // 소수점 첫째 자리 반올림
				};

				students[idx].toString = function () {
					let output = '';
					for (let key in this) {
						if (key != 'getSum' && key != 'getAvg' && key != 'toString') {
							output += key + ' : ' + this[key] + '&nbsp;';
						} else if (key == 'getAvg' || key == 'getSum') {
							output += key.substring(3).toUpperCase() + ' : ' + this[key]() + '&nbsp;';
						}
					}
					return output;
				};
			}
		</script>


5. 함수를 사용한 객체 생성
- 동일한 구조의 객체를 다량 생성할 경우, 객체를 생성하여 반환해 주는 전용 함수를 정의하여 사용

	ex) 객체 생성 함수 활용
		<script>
			// 객체 생성 함수
			function makeStudent(name, kor, mat, eng) {
				return {
					name: name,
					kor: kor,
					mat: mat,
					eng: eng,
					getSum: function () {
						return this.kor + this.mat + this.eng;
					},
					getAvg: function () {
						return (this.getSum() / 3).toFixed(1);
					},
					toString: function () {
						let output = '';
						for (let key in this) {
							if (key != 'getSum' && key != 'getAvg' && key != 'toString') {
								output += key + ' : ' + this[key] + ' &nbsp; ';
							} else if (key == 'getAvg' || key == 'getSum') {
								output += key.substring(3).toUpperCase() + ' : ' + this[key]() + ' &nbsp; ';
							}
						}
						return output;
					}
				};
			}

			// 함수를 이용한 객체 생성 및 배열 추가
			let students = [];
			students.push(makeStudent('홍길동', 99, 98, 90));
			students.push(makeStudent('마길동', 98, 90, 93));
			students.push(makeStudent('김길동', 96, 92, 92));
			students.push(makeStudent('이길동', 92, 95, 94));
			students.push(makeStudent('박길동', 90, 99, 91));
			students.push(makeStudent('최길동', 91, 90, 90));

			// forEach를 활용한 일괄 출력
			students.forEach(element => document.write(element + '<hr>'));
		</script>
