Ch 08. 기본 객체 (표준 내장 객체)


1. String 객체
- 문자열을 생성하고 조작하기 위한 내장 객체

- 대표적인 주요 메서드
  * length : 문자열 길이 반환 (속성)
  * concat(str) : 문자열 결합
  * substring(start, end) : start 인덱스부터 end 앞까지 추출
  * substr(start, count) : start 인덱스부터 count개 만큼 추출
  * indexOf(str) / lastIndexOf(str): 특정 문자열의 시작 위치 탐색 (없으면 -1)
  * trim(): 문자열 양 끝 공백 제거
  * toUpperCase() / toLowerCase() : 대/소문자 변환
  * replace(m, n) / replaceAll(m, n) : 문자열 치환

	ex) String 메서드 활용
		<script>
			let str = "   abc@ ABC @  ";

			console.log('원본:', str);
			console.log('글자 수 length:', str.length);
			console.log('글자 연결 concat:', str.concat('뒷부분'));
			console.log('글자 추출 substring(3, 6):', str.substring(3, 6)); // "abc"
			console.log('글자 추출 substr(3, 6):', str.substr(3, 6));       // "abc@ A"
			console.log('indexOf("@"):', str.indexOf('@'));                // 6
			console.log('lastIndexOf("@"):', str.lastIndexOf('@'));        // 12
			console.log('trim():', str.trim());                            // "abc@ ABC @"
			console.log('toUpperCase():', str.toUpperCase());
			console.log('replace("@", "#"):', str.replace('@', '#'));      // 첫 번째 @만 변경
			console.log('replaceAll("@", "#"):', str.replaceAll('@', '#'));  // 모든 @ 변경
			console.log('공백 전체 제거:', str.replaceAll(' ', ''));
		</script>


1.2 정규표현식 (Regular Expression) 활용
- 패턴을 정의하여 문자열 내 특정 패턴 존재 여부 확인 및 검증에 활용

- 주요 메서드
  * pattern.test(str) : 정규식 패턴과 매칭되면 true, 아니면 false 반환
  * str.match(pattern) : 매칭되는 문자열 배열 반환 (일치하지 않으면 null)

	ex) 정규표현식을 활용한 유효성 검사
		<script>
			var str = 'abcd@ef';

			// 정규표현식 패턴 정의
			var patternNum = /[0-9]/;
			var patternEng = /[a-zA-Z]/;
			var patternKor = /[가-힣]/;
			var patternSpe = /[~`!@#$%^&*()_\-\\|+=*;:'"{}[\]\<>?.,]/;
			var patternEmail = /^\w+@\w+(\.\w+){1,2}$/;

			console.log('숫자 포함 여부:', patternNum.test(str));   // false
			console.log('영어 포함 여부:', patternEng.test(str));   // true
			console.log('특수문자 포함 여부:', patternSpe.test(str)); // true

			var email1 = 'hong@hong.com';
			var email2 = 'hong@hong.com@abc';

			console.log(patternEmail.test(email1)); // true
			console.log(patternEmail.test(email2)); // false
		</script>


2. Array 객체
- 배열을 생성하고 다루는 내장 객체

- 배열 생성 방식
  	* 리터럴 : var arr = [1, 2, 3];
  	* 생성자 : var arr = new Array(); 또는 var arr = new Array(크기);

- 배열 정렬
  	* 기본 sort() : 요소를 문자열로 변환한 후 사전에 적힌 순서대로 정렬 (숫자 비교 시 오류 발생 가능)
  	* 숫자 오름차순/내림차순 정렬 시 콜백함수 지정 필요: arr.sort((left, right) => left - right);

	ex) 숫자 오름차순 정렬 및 객체 배열 정렬
		<script>
			// 1. 단순 숫자 정렬
			var numbers = [52, 273, 103, 32];
			numbers.sort(function (left, right) {
				return left - right; // 오름차순 (내림차순은 right - left)
			});
			console.log(numbers); // [32, 52, 103, 273]

			// 2. Student 객체 배열 총점 기준 내림차순 정렬 후 상위 3명 추출
			function Student(name, kor, math, eng, sci) {
				this.name = name;
				this.kor = kor;
				this.math = math;
				this.eng = eng;
				this.sci = sci;
				this.getSum = function () {
					return this.kor + this.math + this.eng + this.sci;
				};
				this.getAverage = function () {
					return this.getSum() / 4;
				};
			}

			var students = [
				new Student('윤인성', 87, 98, 88, 95),
				new Student('연하진', 92, 98, 96, 98),
				new Student('구지연', 76, 96, 94, 90),
				new Student('나선주', 98, 92, 96, 92),
				new Student('윤아린', 95, 98, 98, 98)
			];

			// 총점 기준 내림차순 정렬
			students.sort(function (left, right) {
				return right.getSum() - left.getSum();
			});

			// 1등부터 3등까지만 잘라내기
			topStudents = students.slice(0, 3);
			console.log(topStudents);
		</script>


3. Date 객체

- 날짜와 시간을 생성하고 조작하는 객체
- 생성 시 Month(월) 인덱스는 0부터 시작 (0 = 1월, 11 = 12월)

	ex) Date 객체 생성 및 연산
		<script>
			// 현재 날짜 기준 7일 뒤 계산
			var date = new Date();
			date.setDate(date.getDate() + 7);

			// 특정 날짜 생성: 2020년 1월 1일 13시 05분 30초 (Month: 0 = 1월)
			var targetDate = new Date(2020, 0, 1, 13, 5, 30);
			console.log(targetDate.toLocaleDateString()); // 지역 날짜 문자열
			console.log(targetDate.toLocaleString());     // 지역 날짜/시간 문자열
		</script>


3.1 날짜 간격 계산
- getTime() 메서드 : 1970년 1월 1일 00:00:00 UTC 기준 경과된 밀리초(ms)를 반환
- 두 Date 객체의 getTime() 차이를 계산하여 일(Day) 단위로 변환 : Math.floor(차이값 / (1000 * 60 * 60 * 24))

	ex) Date 메서드 활용
		// interval.js 모듈로 분리 가능
		Date.prototype.getInterval = function (otherDate) {
			var interval;
			if (this > otherDate) {
				interval = this.getTime() - otherDate.getTime();
			} else {
				interval = otherDate.getTime() - this.getTime();
			}
			return Math.floor(interval / (1000 * 60 * 60 * 24));
		};

		<script>
			var now = new Date();
			var before = new Date(2025, 0, 5); // 2025년 1월 5일
			alert('날짜 간격: ' + now.getInterval(before) + '일');
		</script>


4. Math 객체
- 수학적인 상수와 함수를 위한 정적(Static) 속성과 메서드를 제공하는 객체 (new Math() 인스턴스 생성 불가능)
- 주요 static 메서드
  * Math.abs(x) : 절대값
  * Math.max(x, y, ...) / Math.min(x, y, ...) : 최대값/최소값
  * Math.floor(x) : 내림 / Math.ceil(x) : 올림 / Math.round(x) : 반올림
  * Math.random() : 0 이상 1 미만의 난수 생성

	ex) Math.max 활용
		<script>
			var max = Math.max;
			console.log(max(52, 273, 103, 57, 32)); // 273
		</script>
