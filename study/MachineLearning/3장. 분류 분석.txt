1. 분류 분석(Classification Analysis)

- 분류 분석의 정의
	- 데이터의 독립변수(속성)를 활용한 분류 기준 수립 과정
	- 타겟변수(종속변수)가 범주형(Categorical)인 지도학습 분석 기법

- 주요 활용 사례
	- 고객 등급 예측, 휴면 고객 전환 예측, 상품 구매 여부 예측, 보험 사기자 탐지 등

- 주요 라이브러리 및 설치
	- Python 대표 머신러닝 패키지인 scikit-learn 활용
	- pip install scikit-learn 명령어를 통한 패키지 설치

1.1 Scikit-learn 제공 데이터셋 접근 방식

- Load 계열 (패키지 내장 데이터셋)
	- 패키지 설치 시 함께 제공되는 소규모 실습용 데이터셋
	- 별도 네트워크 연결 없이 즉시 로드 가능 (예 : load_iris(), load_boston())

- Fetch 계열 (외부 다운로드 데이터셋)
	- 데이터의 크기가 크거나 지속 업데이트가 필요한 대규모 데이터셋
	- 최초 실행 시 인터넷 연결을 통한 자동 다운로드 및 캐싱 (예 : fetch_covtype(), fetch_20newsgroups(), fetch_openml())

- Make 계열 (가상 데이터 생성)
	- 알고리즘의 동작 원리 이해 및 성능 테스트 목적으로 생성하는 가상 데이터셋
	- 데이터의 노이즈, 특성 수, 클래스 분리도 등을 사용자가 지정 가능 (예 : make_classification(), make_regression())

2. 분류 분석의 종류

2.1 확률적 모델

- 확률적 모델의 정의
	- 입력 데이터에 대해 각 범주(Class)가 정답일 조건부 확률을 산출하는 분류 모델
	- 예측의 불확실성 및 확신도 측정 가능

- predict_proba()
	- 각 입력 샘플이 각 클래스에 속할 확률값(0.0 ~ 1.0)을 반환하며 모든 클래스 확률의 합은 1로 구성
	- 임계값(Threshold) 조정 및 이진/다중 분류의 정밀한 예측 판단에 활용

- predict_log_proba()
	- predict_proba() 결과에 자연로그(ln)를 적용한 값 반환
	- 매우 작은 확률 곱셈 시 발생하는 연산 오류인 언더플로우(Underflow) 방지 및 계산 안정성 확보 목적

2.1.1 확률적 생성 모델

- 베이즈 정리 기반 확률 계산
	- 데이터의 각 클래스별 특징 확률 분포를 추정한 후 베이즈 정리를 적용하여 사후 확률 산출
		* 베이즈 정리(Bayes' theorem): 새로운 정보나 데이터가 주어졌을 때 기존의 확률(사전 확률)을 업데이트하여 사후 확률 계산

- 데이터 효율성
	- 사전 확률 및 우도(Likelihood) 분포를 활용하여 소량의 데이터셋 환경에서도 안정적인 학습 및 예측 수행
		* 우도(Likelihood) 분포: 특정 파라미터가 주어졌을 때 관측된 데이터가 나타날 확률 density/mass를 파라미터에 대한 함수로 표현한 분포

- QDA (Quadratic Discriminant Analysis)
	- 변수 간 비선형 관계 포착에 유용하며 데이터 수가 충분하고 클래스 간 변동성이 다를 때 효과적
	- 각 클래스별 독립변수 X의 분포가 정규분포를 따른다고 가정
	- 클래스마다 서로 다른 공분산 행렬(Covariance Matrix)을 허용하여 곡선 형태의 이차(Quadratic) 경계면 형성

- NB (Naive Bayesian)
	- 클래스가 주어졌을 때 모든 독립변수들은 서로 통계적으로 완전 독립이라는 가정 적용
	- 강력한 독립성 가정을 통해 파라미터 수를 줄여 계산 복잡도를 낮추며 대용량 텍스트 분류 및 소규모 데이터셋에서 높은 성능 발휘

	ex)
	# 데이터 생성 및 난수 재배열
	from sklearn.datasets import make_classification
	X, y = make_classification(

2.1.2 확률적 판별 모델

- 조건부 확률 분포 직접 추정
	- 데이터의 분포를 별도로 모델링하지 않고 입력 특징에 대한 클래스 확률을 직접 추정

- 우수한 예측 성능 및 높은 해석 가능성
	- 결합 분포 추정에 따른 계산 복잡도를 줄여 실전 예측 성능이 뛰어나며 계수(Weight) 분석을 통한 직관적 해석 용이

- 로지스틱 회귀 (Logistic Regression)
		- 종속변수가 범주형 또는 이진(0 또는 1, Success/Failure)일 경우 활용

- 의사 결정 나무 (Decision Tree)
		- 여러 개의 독립변수 조건을 순차적으로 적용하여 독립변수 전체 공간을 상호 배타적인 영역으로 분할하는 분류 모형
		- 뿌리 노드(Root Node)에서 시작하여 중간 노드(Decision Node)의 조건 판단을 거쳐 최종 끝 노드(Leaf Node)에서 예측 클래스를 결정하는 트리 구조 형태
		- 시각화가 쉬우며 데이터 스케일링(정규화/표준화) 전처리 영향이 적어 우수한 직관성 및 해석력 보유
		- 트리가 깊어질수록 과적합(Overfitting) 위험이 높아지므로 가지치기(Pruning) 및 max_depth 등 하이퍼파라미터 조절 필수

	# 의사 결정 나무
	from sklearn.datasets import load_iris

	import io

	def draw_decision_tree(model, feature_names):
	    dot_buf = io.StringIO()
	    export_graphviz(model, out_file=dot_buf, feature_names=feature_names)
	    graph = pydot.graph_from_dot_data(dot_buf.getvalue())[0]
	    image = graph.create_png()
	    return Image(image)

	draw_decision_tree(dt_model, feature_names=data.feature_names[2:])

	def plot_decision_regions(X, y, model, title):
	    species = ['setosa', 'versicolor', 'virginica']
	    resolution = 0.01
	    markers = ('s', '^', 'o')
	    colors = ('red', 'blue', 'lightgreen')
	    cmap = mpl.colors.ListedColormap(colors)
	    
	    x1_min, x1_max = X[:, 0].min() - 1, X[:, 0].max() + 1
	    x2_min, x2_max = X[:, 1].min() - 1, X[:, 1].max() + 1
	    
	    xx1, xx2 = np.meshgrid(np.arange(x1_min, x1_max, resolution), np.arange(x2_min, x2_max, resolution))
	    
	    Z = model.predict(np.array([xx1.ravel(), xx2.ravel()]).T).reshape(xx1.shape)
	    
	    plt.contour(xx1, xx2, Z, cmap=mpl.colors.ListedColormap(['k']))
	    plt.contourf(xx1, xx2, Z, alpha=0.4, cmap=cmap)
	    plt.xlim(xx1.min(), xx1.max())
	    plt.ylim(xx2.min(), xx2.max())
	    
	    for idx, cl in enumerate(np.unique(y)):
	        plt.scatter(
	            x=X[y == cl, 0], 
	            y=X[y == cl, 1], 
	            alpha=0.8,
	            c=[cmap(idx)], 
	            marker=markers[idx], 
	            s=80, 
	            label=species[cl])
	        
	    plt.xlabel(data.feature_names[2])
	    plt.ylabel(data.feature_names[3])
	    plt.legend(loc='upper left')
	    plt.title(title)
	    
	    return Z

	# 분류 시각화

2.2 판별 함수 모델 (Discriminative Function Models)

- 데이터를 클래스별 영역으로 분할하는 결정 경계(Decision Boundary) 탐색 모델
- 경계면으로부터 대상 데이터까지의 위치 및 거리를 계산하는 판별 함수 활용
- 확률 산출 절차 없이 데이터의 속성을 경계면에 직접 매핑하여 속한 클래스를 판단

- decision_function()
	- 입력 샘플과 결정 경계면 사이의 부호가 있는 거리(signed distance) 또는 판별 점수 반환
	- 서포트 벡터 머신(SVM), 선형 판별 분석(LDA) 등 대표적 판별 모델에서 활용

- Perceptron
	- 단층 단방향 신경망 구조 기반의 초기 선형 분류 모델

- SVC (Support Vector Classifier)
	- C : 규제 매개변수로서 값이 클수록 오차를 적게 허용하고 오버피팅 위험이 증가하며 작을수록 규제가 강해져 언더피팅 위험 존재
	- kernel : 커널 함수 종류 지정 (linear, poly, rbf, sigmoid, precomputed)
	- gamma : RBF, Poly, Sigmoid 커널의 영향력 범위 설정 (scale, auto, 또는 실수)
	- coef0 : Poly 및 Sigmoid 커널에서 사용되는 독립항(상수항) 값 지정
	- shrinking : 축소(Shrinking) 기법 사용 여부 결정
	- probability : 확률 추정(predict_proba) 활성화 여부 설정
	- tol : 학습 중단 결정에 사용할 정지 기준 오차 공차 지정
	- class_weight : 클래스 불균형 처리 설정 (balanced 지정 시 클래스 빈도에 역비례하는 가중치 자동 부여)
	- max_iter : 최대 반복 횟수 제한 설정

- NN (MLPClassifier)
	- 다층 퍼셉트론(MLP) 신경망 구조를 활용한 비선형 분류 모델

	ex)
	# Perceptron
	from sklearn.datasets import load_iris
	import numpy as np
	import pandas as pd
	from sklearn.linear_model import Perceptron

	iris = load_iris()
	iris.data [:5]

	# 행 0 ~ 49 + 100 ~ 149, 열 0, 1
	X = np.r_[iris.data[:50,:2], iris.data[100:,:2]]
	y = np.r_[iris.target[:50], iris.target[100:]]
	X.shape, y.shape

	import matplotlib.pyplot as plt
	plt.scatter(X[:, 0], X[:,1], c=y)

	model = Perceptron(
	    max_iter=100, # 최대 학습 에포크(Epoch) 수
	    eta0=0.1, # 학습률(Learning Rate, η)
	    random_state=1
	).fit(X, y)

	y_pred = model.predict(X)
	pd.crosstab(y, y_pred, rownames=['true'], colnames=['pred'])

	# 잘못 예측한 값 찾아보기
	for idx, (real, pred) in enumerate(zip(y, y_pred)):
	    if real != pred:
	        print(f'{idx} 번째 - 실제값 : {real}, 예측값 : {pred}')

	x_data = [[4.5, 2.3]]
	print('예측 : ', model.predict(x_data))
	print(model.decision_function(x_data))

	x_data = X[0][np.newaxis, :]
	print('예측 : ', model.predict(x_data))

3. 분류모델 성능평가

3.1 sklearn

- 예측 모델의 score 메서드
	- 예측 모델의 score(test_x, test_y) 함수 기본 제공 (분류모델: 정확도 반환, 회귀모델: 결정계수 반환)
- metrics 패키지 함수
	- 분류 모델 성능 검증을 위한 sklearn.metrics 모듈 제공 (혼돈행렬, 정밀도, 재현율, ROC-AUC 등 평가 지표 함수)
- scoring 매개 변수
	- GridSearchCV 및 cross_val_score 등 교차검증 수행 시 성능 평가 기준을 설정하는 매개변수 (scoring='accuracy', 'f1', 'roc_auc' 등)

3.2 혼돈행렬

- accuracy (정확도) : 전체 예측 대상 중 올바르게 분류한 비율
- recall (재현율, 민감도) : 실제 양성 데이터 중 양성으로 올바르게 감지한 비율
- precision (정밀도) : 양성으로 예측한 결과 중 실제 양성인 비율
- Specificity (특이도) : 실제 음성 데이터 중 음성으로 올바르게 감지한 비율 (pos_label=0 설정 시 0을 양성 클래스로 간주하여 계산)
- FP Rate (위양성율, False Positive Rate) : 실제 음성 데이터 중 양성으로 잘못 분류한 비율 (1 - 특이도)

- f1-score : 정밀도와 재현율의 균형을 평가하는 조화평균 지표
- f-beta score : 가중치 매개변수를 통해 정밀도와 재현율의 중요도를 조절한 종합 지표
	- beta < 1 : 정밀도의 가중치가 높음 (고객 만족도 우선)
	- beta > 1 : 재현율의 가중치가 높음 (회사 비용 감축 우선)
	- beta = 1 : 정밀도와 재현율의 가중치가 동일하며 f1-score와 같은 값 반환

- average 매개변수
	- binary (기본값) : 이진 분류에서 1(양성) 클래스에 대한 정밀도 및 재현율만 단일값으로 계산
	- macro (매크로 평균) : 각 클래스별로 평가 지표를 개별 계산한 후 단순평균 산출
	- micro (마이크로 평균) : 전체 클래스의 총 TP, FP, FN 수치를 모두 합산하여 단일 지표로 계산
	- weighted (가중 평균) : 각 클래스별 실제 데이터 개수(샘플 수)를 가중치로 사용하여 평균 산출

	ex)
	import pandas as pd
	from sklearn.metrics import confusion_matrix, accuracy_score, recall_score, precision_score, f1_score, fbeta_score

	# 데이터 로드 및 확인
	result = pd.read_csv('data/model_result.csv')
	result.head()

	# 결측치 여부 확인
	result.isna().sum()

	# 비율 출력
	print('전체 데이터 수 :', result.shape[0])
	print('F:T 비율 : \n', result.y_true.value_counts(normalize=True))

	# 혼돈행렬 - pandas
	pd.crosstab(result.y_true, result.y_pred, margins=True)

	# 혼돈행렬 - sklearn
	confusion_matrix(result.y_true, result.y_pred)

	# 이진 분류에서의 성능 평가 지표
	print('Accuracy :', accuracy_score(result.y_true, result.y_pred))
	print('Precision :', precision_score(result.y_true, result.y_pred))
	print('Recall :', recall_score(result.y_true, result.y_pred))

	# 다중 분류에서의 Precision, Recall
	print('Precision :', precision_score(result.y_true, result.y_pred, average='macro'))
	print('Recall :', recall_score(result.y_true, result.y_pred, average='macro'))

	# f1-score
	print('f1-score :', f1_score(result.y_true, result.y_pred))

	# fbeta score
	# precision의 가중치가 높을 때 (고객의 만족도 우선) ; beta < 1 미만
	print('fbeta_score :', fbeta_score(result.y_true, result.y_pred, beta=0.5))

	# recall의 가중치가 높을 때 (회사의 비용 감축 우선) ; beta > 1 초과
	print('fbeta_score :', fbeta_score(result.y_true, result.y_pred, beta=1.5))

	# 각각의 가중치가 같을 때 ; beta = 1 : f1-score
	print('fbeta_score :', fbeta_score(result.y_true, result.y_pred, beta=1))
	print('   f1-score :', f1_score(result.y_true, result.y_pred))

	# 특이도 (pos_label=0 설정 시 0을 양성 클래스로 간주하여 0 기준의 재현율(즉, 특이도)을 계산함)
	spec = recall_score(result.y_true, result.y_pred, pos_label=0)
	spec

	# 위양성율 (fp rate, 1종 오류(오탐) 비율)
	1 - spec


3.3 ROC Curve

- ROC Curve (Receiver Operating Characteristic Curve)
	- 분류 모델의 임계값(Threshold, 클래스 판별 기준값)을 0에서 1까지 변화시킬 때, 위양성률(Fall-out, FP Rate)의 변화에 따른 재현율(Recall, TP Rate)의 변화 추이를 시각화한 곡선
	- 세로축 : TP rate (재현율)
	- 가로축 : FP rate (위양성율)

- roc_curve() 함수를 통한 FP Rate 및 TP Rate 산출
	- decision_function(X) 또는 predict_proba(X)[:,1] (1 클래스 확률)을 전달하여 계산

	ex)
	from sklearn.datasets import make_classification
	import matplotlib.pyplot as plt
	from sklearn.svm import SVC
	from sklearn.metrics import roc_curve
	from sklearn.linear_model import LogisticRegression
	from sklearn.tree import DecisionTreeClassifier
	import pandas as pd

	# 데이터 생성
	X, y = make_classification(
	    n_samples=100,
	    n_classes=2,
	    n_features=2,
	    n_informative=2,
	    n_redundant=0,
	    random_state=0
	)

	X.shape, y.shape

	plt.scatter(X[:, 0], X[:, 1], c=y, edgecolors='k')
	plt.show()

	# SVC 모델 적합 및 ROC Curve 시각화
	model = SVC(probability=True)
	model.fit(X, y)

	y_pred = model.predict(X)

	fpr, tpr, thresholds = roc_curve(y, model.decision_function(X))
	fpr1, tpr1, thresholds1 = roc_curve(y, model.predict_proba(X)[:,1])
	plt.figure(figsize=(4,3))
	plt.plot(fpr, tpr, c='b', alpha=0.7)
	plt.plot(fpr1, tpr1, c='r', alpha=0.3)
	plt.xlabel('FP rate')
	plt.ylabel('TP rate')
	plt.show()

	# 각 모델의 혼돈행렬이 같을 경우 시각화 비교
	X, y = make_classification(
	    n_samples=1000,
	    weights=[0.95, 0.05],
	    n_classes=2,
	    random_state=5
	)

	X.shape, y.shape

	model1 = LogisticRegression().fit(X, y)
	model2 = SVC(gamma=0.0001, C=3000, probability=True).fit(X,y)
	model3 = DecisionTreeClassifier(random_state=42).fit(X, y)

	pred1 = model1.predict(X)
	pred2 = model2.predict(X)
	pred3 = model3.predict(X)

	# model1의 혼돈행렬
	pd.crosstab(y, pred1)

	# model2의 혼돈행렬
	pd.crosstab(y, pred2)

	# model3의 혼돈행렬
	pd.crosstab(y, pred3)

	fpr1, tpr1, thr1 = roc_curve(y, model1.decision_function(X))
	fpr2, tpr2, thr2 = roc_curve(y, model2.decision_function(X))
	fpr3, tpr3, thr3 = roc_curve(y, model3.predict_proba(X)[:,1])

	plt.plot(fpr1, tpr1, c='r')
	plt.plot(fpr2, tpr2, c='b')
	plt.plot(fpr3, tpr3, c='b')
	plt.show()


3.4 AUC
- AUC (Area Under the ROC Curve)
	- ROC 커브 아래의 전체 면적을 나타내는 단일 수치 지표로 0.5(분류 능력이 없는 모델)에서 1.0(완벽하게 이상적인 모델) 사이의 값을 가짐
	- 모델이 분류 기준값(임계값)의 변화에 영향을 받지 않고 양성과 음성을 얼마나 명확하게 구분하는지 측정하는 종합 성능 평가 지표

	ex)
	from sklearn.metrics import auc
	auc(fpr1, tpr1), auc(fpr2, tpr2), auc(fpr3, tpr3)
