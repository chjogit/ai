2. requests 라이브러리 및 주요 기능

	- requests.get(url, headers=..., params=...) : HTTP 요청을 처리하며 서버에 페이지 요청 전달
		- headers : 크롬 브라우저로 신분을 위장하여 403 및 406 접속 차단 방지
		- params : 검색어, 페이지 번호 등 URL 쿼리를 파라미터로 전달

	- response 주요 응답 속성
		- response.status_code : 접속 응답 상태 확인 (200: 성공/정상, 403/406: 차단, 404: 페이지 없음)
		- response.text : 서버가 전달한 웹페이지의 전체 HTML 원본 텍스트
		- response.content : 디코딩되지 않은 순수 바이너리(bytes) 데이터

	- 로컬 파일 요청 처리
		- requests.Session() 및 FileAdapter()를 사용하여 file:// 경로의 로컬 파일 접근 및 읽기 지원

3. BeautifulSoup 파싱 메서드 및 주요 속성

	- 주요 탐색 메서드
		- soup.select_one(선택자) : 조건에 맞는 첫 번째 엘리먼트 반환
		- soup.select(선택자) : 조건에 맞는 전체 엘리먼트를 리스트 형태로 반환
		- soup.find(태그, 속성) : 조건에 맞는 첫 번째 엘리먼트 반환
		- soup.find_all(태그, 속성) : 조건에 맞는 전체 엘리먼트를 리스트 형태로 반환

	- 주요 엘리먼트 속성 및 추출
		- el.text / el.string : 엘리먼트 내부의 텍스트 추출
		- el.attrs : 엘리먼트의 모든 속성들을 딕셔너리로 반환
		- el.attrs.get(속성) : 특정 속성값 반환 (데이터가 없을 경우 None 반환)
		- el.name : 해당 태그의 이름 반환

	- 존재하지 않는 엘리먼트 접근 시 반환 규칙
		- find, select_one : 존재하지 않을 경우 None 반환
		- find_all, select : 존재하지 않을 경우 빈 리스트([]) 반환

- User-Agent 헤더를 추가한 멜론 TOP 100 수집
		- User-Agent : 접속자의 브라우저 및 운영체제 정보를 담은 헤더(신분증) 값
		- requests.get(url)이나 urlopen(url)을 기본 상태로 사용하면 User-Agent에 'Python'으로 표시됨
		- 멜론(Melon) 등 보안이 설정된 사이트는 'Python' 헤더를 봇(Bot)으로 간주하여 접속을 차단함 (Response status 406/403)
		- 주요 HTTP 상태 코드
			* 200 (OK) : 성공
			* 403 (Forbidden) : 접근 권한 없음 (User-Agent 차단)
			* 406 (Not Acceptable) : 요청 헤더 자격 미달 (Accept, Accept-Language 등 누락)
			* 429 (Too Many Requests) : 너무 짧은 시간에 많은 요청을 보냄 (time.sleep 필요)

	ex) 멜론 차트 크롤링 (User-Agent 설정)

		- python-dotenv 패키지의 load_dotenv() 및 os.getenv() 함수 사용

	ex) 네이버 지식iN 검색 API 수집
	import os
	import urllib.request
	import json
	import pandas as pd
	from dotenv import load_dotenv

	load_dotenv()
	client_id = os.getenv('CLIENT_ID')
	client_secret = os.getenv('CLIENT_SECRET')

	encText = urllib.parse.quote("인스파이어아레나")
	url = f"https://openapi.naver.com/v1/search/kin.json?query={encText}"

	headers = {
		'X-Naver-Client-Id': client_id,
		'X-Naver-Client-Secret': client_secret
	}
	request = urllib.request.Request(url, headers=headers)
	response = urllib.request.urlopen(request)

	if response.getcode() == 200:
		response_body = response.read()
		data = json.loads(response_body)
		
		items = data['items']
		items_list = []
		for item in items:
			title = item['title'].replace('<b>','').replace('</b>','')
			link = item['link']
			description = item['description'].replace('<b>','').replace('</b>','')
			items_list.append([title, link, description])

		pd.DataFrame(items_list, columns=['title','link','description'])

	ex) 네이버 이미지 검색 API 및 로컬 이미지 다운로드
	import os
	import requests
	import json
	import pandas as pd
	from dotenv import load_dotenv

	load_dotenv()

	def save_img(attr, idx, link, query):
		response = requests.get(link)
		file_ext = link[link.rfind('.'):]
		
		quote_index = file_ext.find('?')
		if quote_index != -1:
			file_ext = file_ext[:quote_index]
			
		quote_index = file_ext.find('%')
		if quote_index != -1:
			file_ext = file_ext[:quote_index]
		
		valid_ext = [".jpg",".jpeg",".png",".gif",".webp",".avif",".svg",".bmp",".tiff"]
		file_ext = file_ext if file_ext in valid_ext else '.jpg'
		
		img = response.content 
		with open(f'image/{attr}_{idx:03}_{query}{file_ext}', 'wb') as f:
			f.write(img)

	def save_file(query):
		client_id = os.getenv('CLIENT_ID')
		client_secret = os.getenv('CLIENT_SECRET')

		url = "https://openapi.naver.com/v1/search/image.json"
		params = {'query': query, 'display': 100}
		headers = {
			'X-Naver-Client-Id': client_id,
			'X-Naver-Client-Secret': client_secret
		}
		response = requests.get(url, params=params, headers=headers)

		items = response.json()['items']
		items_list = []
		for idx, item in enumerate(items):
			title = item['title']
			link = item['link']
			thumbnail = item['thumbnail']
			sizeheight = item['sizeheight']
			sizewidth = item['sizewidth']
			items_list.append([title, link, thumbnail, sizeheight, sizewidth])
			
			save_img('메인', idx, link, query)
			save_img('썸네일', idx, thumbnail, query)
			if idx % 20 == 0:
				print(f'==={idx:02}%===')
			
		result = pd.DataFrame(items_list, columns=['title','link','thumbnail','sizeheight','sizewidth'])
		result.to_csv('image/img_list.csv', index=False)
		print('이미지 및 CSV 저장 완료')
		return result
