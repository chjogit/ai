1. 패키지 불러오기 및 하이퍼파라미터 설정

- 영화평 감성 분석을 위한 주요 패키지와 데이터 처리, 모델 생성, 평가에 필요한 라이브러리 임포트


	ex) 모델 하이퍼파라미터 정의 및 설정 (파라미터 설정에 따른 학습 속도 및 성능 차이 발생)
	MY_WORDS = 10000 # imdb 데이터셋의 단어 수
	MY_LENGTH = 200 # 영화평 단어 수 2000개까지 독립 변수
	MY_EMBED = 64 # 임베딩 레이어의 출력 차원
	MY_HIDDEN = 128 # LSTM의 units 수

	MY_EPOCH = 10 # 반복 학습 수
	MY_BATCH = 200 # 매번 가져오는 데이터 수


2. 데이터 불러오기

- IMDB 영화평 데이터셋 로드 및 학습용/검증용(테스트용) 데이터 분할


	ex) num_words 옵션을 통한 출현 빈도 상위 MY_WORDS개 단어 추출
	(X_train, y_train), (X_test, y_test) = imdb.load_data(
		num_words=MY_WORDS)


3. 단어 인덱스 변환 및 디코딩 함수 정의

- IMDB 단어 인덱스 사전({'word': id})의 디코딩용 사전({id: 'word'}) 재구성
- 숫자 시퀀스 변환 영화평 데이터의 자연어 문자열 복원 함수 정의
- d - 3 처리 : IMDB 데이터셋 특수 토큰(0 : 패딩, 1 : 문장 시작, 2 : 미등록 단어) 인덱스 할당에 따른 오프셋 조정 적용
	

	ex) 영화평 샘플의 단어 길이 확인 출력 함수 정의
	word_to_id = imdb.get_word_index()

5. 트랜스포머 인코더 기반 이진 분류 모델 생성

- 입력층 : 문장 길이 MY_LENGTH 규격의 입력 형태 정의

- 임베딩층 및 위치 인코딩
	- 입력 단어 대상 위치(Position) 인덱스 생성 및 위치 임베딩 구성
	- 위치 인코딩(PE)을 통한 병렬 입력 단어 대상 순서 정보 번호표 부여 및 임베딩 추가
	- 단어 임베딩과 위치 임베딩 결합을 통한 위치 정보 포함 입력(POS_ENC_OUTPUT) 형성

- 셀프 어텐션 (Self-Attention)
	- MultiHeadAttention 활용 다각도(Head) 단어 간 연관성 계산
	- 자기 자신(POS_ENC_OUTPUT)의 Query, Key, Value 동시 전달을 통한 Self-Attention 적용

- 잔차 연결 및 레이어 정규화 (Add & Norm)
	- 입력 데이터와 어텐션 결과 결합을 통한 기울기 소실 문제(Gradient Vanishing) 방지 및 LayerNormalization 적용

- 피드포워드 네트워크 (FFN)
	- 어텐션 수집 관계 정보의 개별 단어 단위 다층 Dense 레이어 정립
	- L2 정규화 및 Dropout(0.3) 적용을 통한 과적합 방지
	- FFN output 대상 잔차 연결 및 레이어 정규화 재수행

- 1D 축약 및 최종 출력층
	- GlobalAvgPool1D 활용 시퀀스 전체 정보의 대표 벡터 축약
	- 긍정/부정 판단 이진 분류 출력을 위한 Sigmoid 활성화 함수 적용

	ex) 트랜스포머 인코더 기반 모델 생성
	INPUTS = Input(shape=(MY_LENGTH,))
	INPUT_EMBEDDING = Embedding(
		input_dim=MY_WORDS,
		output_dim=MY_EMBED
	)(INPUTS)

	POSITIONS = range(start=0, limit=MY_LENGTH)
	POS_ENCODING = Embedding(
		input_dim=MY_LENGTH,
		output_dim=MY_EMBED
	)(POSITIONS)
	POS_ENC_OUTPUT = POS_ENCODING + INPUT_EMBEDDING

	ATTENTION_OUTPUT = MultiHeadAttention(
		num_heads=3,
		key_dim=MY_EMBED//3,
		dropout=0.3
	)(POS_ENC_OUTPUT,
	  POS_ENC_OUTPUT)

	X = add([POS_ENC_OUTPUT, ATTENTION_OUTPUT])
	X = LayerNormalization()(X)

	FFN = Sequential([
		Dense(
			units=MY_HIDDEN,
			activation='elu',
			kernel_regularizer=l2(0.001)),
		Dropout(0.3),
		Dense(
			units=MY_EMBED,
			activation=None,
			kernel_regularizer=l2(0.001))
	])(X)

	X = add([FFN, X])
	X = LayerNormalization()(X)

	X = GlobalAvgPool1D()(X)
	X = Dropout(0.3)(X)

	X = Dense(MY_HIDDEN, activation='elu')(X)
	X = Dropout(0.3)(X)
	OUTPUTS = Dense(1, activation='sigmoid')(X)

	model = Model(inputs=INPUTS, outputs=OUTPUTS, name='model')
	model.summary()


6. 모델 학습 설정 및 학습

- 손실 함수(binary_crossentropy) 및 최적화 알고리즘(adam) 설정
- EarlyStopping 설정을 통한 검증 데이터 손실(val_loss) 3회 연속 미개선 시 자동 조기 종료 및 최적 가중치 복원
- time() 함수 활용 모델 학습 소요 시간 측정

	ex) 모델 학습
	model.compile(loss='binary_crossentropy', optimizer='adam', metrics=['acc'])

	earlyStopping = EarlyStopping(
		monitor='val_loss',
		patience=3,
		mode='min',
		restore_best_weights=True,
		verbose=1
	)

	hist = model.fit(
		X_train, y_train,
		validation_split=0.2,
		epochs=MY_EPOCH,
		batch_size=MY_BATCH,
		verbose=2,
		callbacks=[earlyStopping]
	)

7. 모델 평가 및 결과 시각화

- matplotlib 활용 학습 과정 중 epoch별 train/val loss 및 accuracy 변동 그래프 시각화
- 테스트 데이터셋(X_test, y_test) 활용 학습 모델의 최종 손실 값 및 정확도 평가
- 예측 결과(pred) 임계값(0.5) 기준 0(부정) 또는 1(긍정) 분류
- pandas crosstab 출력을 통한 혼돈 행렬(Confusion Matrix) 형태의 실제 값 및 예측 값 분류 성과 분석

	ex) 모델 평가 및 시각화
	fig, loss_ax = plt.subplots(figsize=(10,6))
	loss_ax.plot(hist.history['loss'], 'y', label='train_loss')
	loss_ax.plot(hist.history['val_loss'], 'r', label='val_loss')
	loss_ax.set_xlabel('epoch')
	loss_ax.set_ylabel('loss', rotation=0)

	acc_ax = loss_ax.twinx()

	acc_ax.plot(hist.history['val_acc'], 'b', label='val_accuracy')
	acc_ax.set_ylabel('accuracy')
	loss_ax.legend(loc='center right', bbox_to_anchor=(1.5, 0.6), ncol=1)
	acc_ax.legend(loc='center right', bbox_to_anchor=(1.5, 0.8), ncol=1)
	plt.show()

	loss, acc = model.evaluate(X_test, y_test)
