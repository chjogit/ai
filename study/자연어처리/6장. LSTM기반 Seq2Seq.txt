6장. LSTM기반 Seq2Seq
- 스마트 번역기

1. Seq2Seq (Sequence-to-Sequence) 
	- 입력 시퀀스를 받아 다른 형태의 출력 시퀀스로 변환하는 신경망 구조 (예: 구글 GNMT 등 기계 번역)

- 작동 원리
	- 인코더(Encoder)와 디코더(Decoder) 두 개의 RNN/LSTM 레이어가 연결된 구조
	- 인코더 : 입력 문장(영어)을 읽어 모든 정보를 하나의 컨텍스트 벡터(Context Vector; 마지막 시점의 은닉 상태 h 및 셀 상태 c)로 압축
	- 디코더 : 인코더가 전달한 컨텍스트 벡터를 초기 상태(initial_state)로 전달받아 모범 답안 입력과 결합하여 목적 언어(한글)로 변환 출력

- 특수 토큰
	- S (Start) : 디코더 문장 시작을 알리는 구분자 토큰 (디코더 입력 문장 시작 부분에 추가)
	- E (End) : 디코더 문장 종료를 알리는 구분자 토큰 (디코더 출력 타겟 문장 끝 부분에 추가)
	- P (Padding) : 문장 길이를 맞추기 위한 공백 패딩 토큰

2. 데이터 전처리

- 알파벳 및 글자 집합 구성
	- 특수 토큰(S, E, P) 및 영문 알파벳, 한글 고유 문자 세트를 추출하여 통합 단어 사전(alpha) 구성
	- char_to_num: 문자별 고유 정수 인덱스를 매핑한 딕셔너리

- 원-핫 인코딩 기법
	- to_categorical(data, num_classes) : Keras 내장 함수 활용
	- np.eye(total_size)[data] : NumPy 배열 인덱싱을 이용한 원-핫 인코딩 변환

- 인코더/디코더 입력 및 출력 생성 함수 (encoding)
	- 인코더 입력 (enc_in) : 영어 데이터 → 정수 인덱스 → 원-핫 인코딩
	- 디코더 입력 (dec_in) : 'S' + 한글 데이터 → 정수 인덱스 → 원-핫 인코딩
	- 디코더 출력 (dec_out) : 한글 데이터 + 'E' → 정수 인덱스 (sparse_categorical_crossentropy 적용을 위해 2차원 리스트 구조 유지를 적용)


	ex) 데이터 준비

	# 데이터 로드
	raw = pd.read_csv('data/translate.csv')
	eng_kor = raw.values.tolist()

	# 알파벳 및 한글 낱말 사전 생성
	e_alpha = [c for c in 'SEPabcdefghijklmnopqrstuvwxyz']
	korean = ''.join([data[1] for data in eng_kor])
	k_alpha = list(set([ch for ch in korean]))
	k_alpha.sort()

	alpha = e_alpha + k_alpha
	alpha_total_size = len(alpha)

	# 문자-인덱스 매핑 사전 생성
	char_to_num = {ch: i for i, ch in enumerate(alpha)}

	# 하이퍼파라미터 설정
	MY_HIDDEN = 128
	MY_EPOCH = 200

	ex) 인코더/디코더 데이터 전처리
	def encoding(eng_kor_data=eng_kor):
		enc_in = []
		dec_in = []
		dec_out = []

		for data in eng_kor_data:
			# 인코더 입력
			eng = [char_to_num.get(ch) for ch in data[0]]
			eng_one = to_categorical(eng, num_classes=alpha_total_size)
			enc_in.append(eng_one)

			# 디코더 입력 ('S' 추가)
			kor = [char_to_num.get(ch) for ch in 'S' + data[1]]
			kor_one = np.eye(alpha_total_size)[kor]
			dec_in.append(kor_one)

			# 디코더 출력 ('E' 추가)
			kor_target = [[char_to_num.get(ch)] for ch in data[1] + 'E']
			dec_out.append(kor_target)

		return np.array(enc_in), np.array(dec_in), np.array(dec_out)

	# 데이터 변환
	X_enc, X_dec, Y_dec = encoding(eng_kor)

3. 모델 생성 및 학습

- LSTM 파라미터 옵션
	- return_state=True : LSTM의 마지막 출력값 외에 마지막 은닉 상태(state_h)와 셀 상태(state_c)를 함께 반환하여 디코더의 initial_state로 주입
	- return_sequences=True : 디코더 LSTM에서 모든 시점(time step)마다의 출력을 반환하도록 설정

- 손실 함수 선택
	- sparse_categorical_crossentropy : 타겟 레이블이 원-핫 인코딩이 아닌 정수(Integer) 형태(dec_out)일 때 사용하는 다중 분류 손실 함수


	ex) Seq2Seq 모델
	# 인코더 정의
	ENC_IN = Input(shape=(None, alpha_total_size))
	_, state_h, state_c = LSTM(
		units=MY_HIDDEN,
		return_state=True
	)(ENC_IN)

	link = [state_h, state_c]

	# 디코더 정의
	DEC_IN = Input(shape=(None, alpha_total_size))
	DEC_MID = LSTM(
		units=MY_HIDDEN,
		return_sequences=True
	)(DEC_IN, initial_state=link)

	DEC_OUT = Dense(units=alpha_total_size, activation='softmax')(DEC_MID)

	# 최종 모델 정의
	model = Model(
		inputs=[ENC_IN, DEC_IN],
		outputs=DEC_OUT,
		name='model'
	)
	model.summary()

	ex) 모델 학습
	model.compile(
		loss='sparse_categorical_crossentropy',
		optimizer='rmsprop',
		metrics=['accuracy']
	)

	hist = model.fit(
		[X_enc, X_dec], Y_dec,
		epochs=MY_EPOCH,
		verbose=0
	)

	model.evaluate([X_enc, X_dec], Y_dec)

	ex) 번역 예측 및 모델 테스트
	easy_test = [
		['down', 'pp'],
		['desk', 'pp'],
		['love', 'pp'],
		['wood', 'pp']
	]

	enc_in_test, dec_in_test, _ = encoding(easy_test)

	pred = model.predict([enc_in_test, dec_in_test])

	for i in range(len(pred)):
		eng = easy_test[i][0]
		hat = pred[i].argmax(axis=-1)
		kor = ''.join([alpha[num] for num in hat[:-1]])
		print(f'{eng} : {kor}')
